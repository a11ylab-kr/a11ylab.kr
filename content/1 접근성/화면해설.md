# 개요

화면해설은 영상에서 눈으로만 알 수 있는 정보를 말이나 별도 음성으로 설명해 주는 접근성 서비스이다. 영어로는 `audio description`이라고 하며, 국내에서는 음성해설이라는 말도 함께 쓰인다.

인물의 행동, 표정, 장면 전환, 배경, 화면 속 글자처럼 대사나 효과음만으로는 알기 어려운 시각 정보를 설명한다. 보통 대사와 중요한 소리를 방해하지 않는 틈에 삽입하지만, 교육 영상처럼 처음부터 말 속에 시각 정보를 자연스럽게 포함하는 방식도 가능하다.[^1]

# 제공 방식

화면해설은 제작 방식에 따라 여러 형태로 제공될 수 있다.

- 통합형 해설: 발표자나 내레이션이 처음부터 필요한 시각 정보를 말로 설명한다.
- 별도 해설 음성: 원본 영상에 해설 음성을 추가한 버전을 따로 제공한다.
- 별도 파일: 시간 정보가 있는 텍스트나 오디오 파일을 플레이어가 불러와 동기화한다.
- 확장 화면해설: 설명할 시간이 부족한 경우 영상을 잠시 멈추거나 별도 버전에서 더 긴 설명을 제공한다.

WCAG에서는 사전 녹화된 동영상 콘텐츠에 대해 수준 A에서 화면해설 또는 미디어 대안을 요구하고, 수준 AA에서는 사전 녹화된 동영상에 화면해설을 제공하도록 요구한다.[^2]

# 좋은 화면해설의 조건

좋은 화면해설은 많이 말하는 것이 아니라, 이해에 필요한 시각 정보를 적절한 때에 전달하는 것이다.

- 이야기 이해에 필요한 행동과 장면 변화를 우선한다.
- 화면 속 중요한 글자, 이름, 장소, 시간 정보를 놓치지 않는다.
- 대사와 효과음이 전달하는 정보를 불필요하게 반복하지 않는다.
- 해설자의 해석이나 평가보다 관찰 가능한 정보를 중심으로 쓴다.
- 설명이 늦게 들어가 장면 이해를 방해하지 않도록 시간 배치를 조정한다.

# 접근성 관점에서의 의미

화면해설은 시각장애인의 영상 접근권과 직접 연결된다. 영화, 방송, 온라인 강의, 공공 안내 영상, 공연 기록 영상에서 화면해설이 없으면 핵심 정보가 빠진 채 콘텐츠를 접하게 된다.

다만 화면해설은 사후 보정만으로 해결하기 어렵다. 촬영, 대본, 편집, 자막, 플레이어 기능을 기획 단계에서 함께 고려해야 비용과 품질 문제가 줄어든다. 접근 가능한 영상은 화면해설을 마지막에 덧붙이는 방식보다, 처음부터 설명 가능한 구조로 만들어질 때 더 안정적이다.
