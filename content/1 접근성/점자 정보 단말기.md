# 개요

점자 정보 단말기는 시각장애인이 [[점자]]와 음성을 이용해 문서를 읽고 쓰고, 파일을 관리하며, 인터넷과 학습 자료에 접근할 수 있도록 만든 휴대용 [[보조공학기술]] 기기이다.

일반적으로 [[점자 표시 장치]], 점자 입력 키, 음성 출력, 문서 편집기, 파일 관리자, 메일·웹·일정 기능 등을 포함한다. 제품에 따라 계산기, 미디어 플레이어, OCR, 사전, 학습 도구, 외부 기기 연결 기능도 제공한다.

# 점자 표시 장치와의 관계

점자 정보 단말기는 [[점자 표시 장치]]를 포함하는 경우가 많지만 둘은 같은 말이 아니다. 점자 표시 장치는 주로 다른 기기의 화면 정보를 점자로 출력하는 장치이고, 점자 정보 단말기는 자체 운영체제와 앱을 갖춘 독립형 기기에 가깝다.

다만 실제 제품에서는 경계가 흐려진다. 점자 정보 단말기는 외부 컴퓨터나 스마트폰에 연결되어 점자 표시 장치처럼 쓰일 수 있고, 일부 점자 표시 장치도 메모장이나 파일 관리 기능을 제공한다.

# 접근성 관점

점자 정보 단말기는 음성 중심 접근만으로는 부족한 작업에서 중요하다. 철자 확인, 외국어 학습, 긴 문서 편집, 수식·표·코드 읽기, 조용한 환경에서의 작업은 점자 출력과 점자 입력이 있을 때 더 안정적이다.

최근에는 [[한소네 7]]처럼 인공지능 기능을 결합한 제품도 등장하고 있다. 이 흐름은 점자 정보 단말기가 단순 문서 작성 도구를 넘어, AI와 점자 문해력을 연결하는 보조공학 플랫폼으로 확장될 가능성을 보여 준다.
