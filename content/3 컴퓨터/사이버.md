# 개요

사이버는 컴퓨터와 네트워크를 통해 만들어지는 정보 환경, 온라인 공간, 디지털 상호작용을 가리키는 말이다. 사이버 보안, 사이버 공간, 사이버 범죄, 사이버 교육처럼 여러 표현에 붙어 쓰인다.

# 의미의 범위

사이버는 단순히 인터넷을 뜻하지 않는다. 컴퓨터 시스템, 네트워크, 데이터, 사용자 계정, 온라인 커뮤니티, 원격 서비스, 자동화된 제어 시스템까지 포함하는 넓은 개념으로 쓰인다.

# 접근성 관점

사회 활동이 사이버 공간으로 옮겨 갈수록 접근성은 물리적 공간의 편의시설만큼 중요해진다. 행정, 교육, 금융, 문화, 고용이 온라인으로 제공될 때 [[웹 접근성]], 문서 접근성, 인증 절차 접근성이 함께 보장되어야 한다.
