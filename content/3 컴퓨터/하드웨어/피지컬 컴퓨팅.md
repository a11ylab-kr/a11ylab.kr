# 개요

피지컬 컴퓨팅은 센서와 구동 장치를 이용해 물리 세계와 컴퓨터가 상호작용하도록 만드는 분야이다. 사람이 버튼을 누르거나 빛, 온도, 거리, 움직임이 변하면 컴퓨터가 이를 입력으로 읽고, LED, 모터, 소리, 진동 같은 출력으로 반응한다.

# 구성

- 입력: 버튼, 스위치, 거리 센서, 온도 센서, 마이크, 카메라
- 처리: 마이크로컨트롤러, 컴퓨터, 소프트웨어
- 출력: LED, 모터, 스피커, 디스플레이, 진동 장치

Arduino, Raspberry Pi, micro:bit 같은 도구가 교육과 프로토타이핑에 많이 쓰인다.

# 접근성 관점

피지컬 컴퓨팅은 보조공학과 잘 만난다. 사용자에게 맞는 스위치, 촉각 알림, 환경 제어 장치, 대체 입력 장치, 교육용 접근성 도구를 직접 만들거나 실험할 수 있기 때문이다.

다만 실제 사용 기기로 만들려면 안전성, 내구성, 유지보수, 사용자의 신체 조건, 오류 상황을 함께 고려해야 한다.
