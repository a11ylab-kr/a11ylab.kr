# 개요

한 주기 이론은 컴퓨터나 전자 장치의 동작을 하나의 반복 주기 단위로 이해하려는 설명 방식이다. 맥락에 따라 클록 사이클, 처리 주기, 제어 주기처럼 서로 다른 의미로 쓰일 수 있다.

# 컴퓨터에서의 주기

컴퓨터 하드웨어는 보통 클록 신호에 맞추어 명령을 가져오고, 해석하고, 실행하고, 결과를 저장한다. 이 과정을 하나의 주기 또는 여러 주기의 조합으로 설명할 수 있다.

# 교육적 의미

초심자에게는 “입력 → 처리 → 출력 → 피드백”처럼 한 바퀴 도는 구조로 시스템을 설명하면 이해가 쉽다. 피지컬 컴퓨팅에서도 센서 입력을 읽고, 조건을 판단하고, 모터나 LED 같은 출력 장치를 제어하는 흐름을 반복 주기로 볼 수 있다.

# 접근성 관점

접근성 기능도 한 번 설정하고 끝나는 것이 아니라 반복 주기로 관리해야 한다. 요구 확인, 설계, 구현, 테스트, 사용자 피드백, 수정이 계속 돌아가야 한다.
