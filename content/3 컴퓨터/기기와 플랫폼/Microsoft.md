# 개요

Microsoft는 Windows, Office, Azure, GitHub, Xbox, 개발 도구와 클라우드 서비스를 제공하는 기술 기업이다.

# 주요 영역

개인용 운영체제 [[Windows]], 문서 작성 도구 [[Word]], 클라우드 플랫폼 [[Azure]], 코드 편집기 [[Visual Studio Code]], 개발 협업 플랫폼 [[GitHub]] 등이 Microsoft 생태계에 속한다.

# 접근성 관점

Microsoft 제품은 공공·교육·업무 환경에서 널리 쓰이기 때문에 접근성 영향이 크다. 운영체제 접근성 기능, Office 문서 접근성 검사, Teams와 브라우저 접근성, 개발 도구 접근성이 모두 사용자 경험에 영향을 준다.
