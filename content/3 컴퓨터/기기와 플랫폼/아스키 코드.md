# 개요

아스키 코드는 영어 알파벳, 숫자, 문장 부호, 제어 문자를 숫자로 표현하기 위해 만든 문자 인코딩 체계이다. ASCII는 American Standard Code for Information Interchange의 줄임말이다.

# 특징

초기 컴퓨터와 통신 시스템에서 널리 쓰였으며, 현대 문자 인코딩인 Unicode와 UTF-8도 아스키와의 호환성을 중요하게 다룬다. 아스키 범위의 영문자와 숫자는 많은 시스템에서 가장 기본적인 문자 집합으로 취급된다.

# 접근성 관점

문자 인코딩이 잘못되면 화면 읽기 프로그램, 검색, 복사·붙여넣기, 파일 변환에서 문제가 생긴다. 특히 한글 문서와 웹페이지에서는 UTF-8 같은 유니코드 기반 인코딩을 정확히 지정하는 일이 중요하다.
