# 개요

Azure는 Microsoft가 제공하는 클라우드 컴퓨팅 플랫폼이다. 서버, 저장소, 데이터베이스, 네트워크, 인공지능, 개발 도구, 보안 서비스 등을 인터넷을 통해 사용할 수 있게 한다.

기업과 개발자는 Azure를 이용해 직접 물리 서버를 운영하지 않고도 웹서비스, 데이터 분석, AI 기능, 업무 시스템을 구축할 수 있다.

# 특징

- 가상 머신과 컨테이너 실행
- 데이터베이스와 저장소 서비스
- Microsoft 365, Windows, Active Directory와의 연동
- AI와 머신러닝 서비스
- 보안, 모니터링, 배포 자동화 도구

# 접근성 관점

클라우드 플랫폼의 접근성은 관리 콘솔, 문서, API, 교육 자료, 고객 지원의 접근성과 연결된다. 클라우드 서비스 자체가 접근 가능하지 않으면 장애가 있는 개발자와 운영자가 인프라를 관리하기 어렵다.

또한 Azure 위에 만들어지는 서비스도 접근성 책임을 가진다. 클라우드가 제공하는 기본 구성요소와 템플릿이 접근성을 잘 지원할수록, 그 위에 올라가는 서비스의 접근성 기반도 좋아진다.
