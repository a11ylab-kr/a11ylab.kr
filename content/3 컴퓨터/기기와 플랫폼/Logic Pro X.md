# 개요

Logic Pro X는 Apple의 전문 음악 제작 소프트웨어인 Logic Pro의 과거 명칭이다. 녹음, 편집, 믹싱, MIDI 작업, 가상 악기, 플러그인 기능을 제공한다.

# 쓰임

작곡, 편곡, 팟캐스트 편집, 사운드 디자인, 음악 교육, 오디오 후반 작업에 쓰인다. macOS 환경에서 동작하며, Apple의 오디오 생태계와 잘 연결된다.

# 접근성 관점

음악 제작 소프트웨어는 화면 구조가 복잡해 접근성 장벽이 생기기 쉽다. 키보드 단축키, 화면 읽기 지원, 트랙과 플러그인 이름 읽기, 미터 정보의 대체 표현이 중요하다.
