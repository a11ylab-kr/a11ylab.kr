# 개요

Windows는 [[Microsoft]]가 개발·제공하는 개인용 컴퓨터 운영체제 제품군이다. 데스크톱, 노트북, 태블릿, 업무용 PC, 일부 서버 환경에서 널리 사용된다.

# 특징

Windows는 그래픽 사용자 인터페이스, 다양한 하드웨어와 소프트웨어 호환성, 기업 관리 기능, 게임과 업무용 프로그램 생태계를 특징으로 한다.

# 접근성 관점

Windows에는 내레이터, 돋보기, 고대비, 자막, 음성 입력, 키보드 접근성 기능이 포함되어 있다. 또한 JAWS, NVDA 같은 외부 화면 읽기 프로그램과 점자 표시 장치가 많이 쓰이는 플랫폼이기도 하다.
