# 개요

문서 작성 프로그램은 글, 표, 그림, 각주, 머리말과 꼬리말 등을 배치해 문서를 만드는 소프트웨어이다. Microsoft Word, 아래아한글, Google Docs, LibreOffice Writer 등이 대표적이다.

# 주요 기능

제목 스타일, 문단 서식, 목록, 표, 이미지 삽입, 각주, 맞춤법 검사, 변경 내용 추적, PDF 내보내기 기능을 제공한다.

# 접근성 관점

문서 작성 프로그램에서 접근 가능한 문서를 만들려면 시각적 꾸밈보다 구조를 먼저 잡아야 한다. 제목 스타일, 목록, 표 머리글, 이미지 대체 텍스트, 언어 설정, 충분한 대비가 중요하다.
