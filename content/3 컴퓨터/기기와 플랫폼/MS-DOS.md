# 개요

MS-DOS는 Microsoft Disk Operating System의 줄임말로, 초기 IBM PC 호환 컴퓨터에서 널리 쓰인 명령줄 기반 운영체제이다.

# 특징

사용자는 그래픽 화면 대신 명령어를 입력해 파일을 관리하고 프로그램을 실행했다. Windows 초기 버전은 MS-DOS 위에서 실행되거나 MS-DOS와 밀접하게 연결되어 있었다.

# 접근성 관점

MS-DOS 환경은 텍스트 기반이라 화면 읽기 프로그램과 결합하기 쉬운 면도 있었지만, 그래픽과 멀티미디어, 현대적 접근성 API는 부족했다. 당시 보조공학은 별도 음성 합성 장치나 점자 장치와 함께 구성되는 경우가 많았다.
