# 개요

BlueSky는 분산형 소셜 네트워크 구조를 지향하는 [[SNS]] 플랫폼이다. 짧은 글, 이미지, 링크, 답글, 재게시 기능을 제공하며, AT Protocol을 기반으로 한 개방형 소셜 웹을 표방한다.

# 특징

BlueSky는 계정, 서버, 알고리즘 선택권을 분산하려는 방향을 가진다. 중앙 플랫폼 하나가 모든 규칙과 노출을 통제하는 구조에서 벗어나려는 시도라는 점에서 주목받는다.

# 접근성 관점

분산형 소셜 미디어에서도 기본 접근성은 여전히 중요하다. 이미지 대체 텍스트, 키보드 접근성, 화면 읽기 호환성, 명확한 알림 구조, 사용자가 조절할 수 있는 피드와 차단 기능이 필요하다.
