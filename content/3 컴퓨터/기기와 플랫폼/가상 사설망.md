# 개요

가상 사설망은 공용 인터넷 위에 암호화된 통신 경로를 만들어, 사용자가 사설망에 접속한 것처럼 통신하게 하는 기술이다. 영어로는 VPN, Virtual Private Network라고 한다.

# 쓰임

VPN은 회사 내부망 접속, 원격 근무, 공공 와이파이에서의 통신 보호, 지역 네트워크 연결, 개발·운영 환경 접근에 쓰인다.

# 주의할 점

VPN은 통신 경로를 보호하는 도구이지 모든 보안을 자동으로 해결하는 도구는 아니다. VPN 제공자와 기관 관리자는 사용자의 트래픽을 볼 수 있을 수 있고, 잘못된 설정은 접속 장애나 속도 저하를 만들 수 있다.

# 접근성 관점

원격근무와 원격교육에서 VPN이 필수일 때, 로그인 절차와 인증 앱, 오류 메시지, 고객 지원이 접근 가능해야 한다. VPN 접속이 복잡하면 장애가 있는 사용자에게 업무·학습 접근 장벽이 된다.
