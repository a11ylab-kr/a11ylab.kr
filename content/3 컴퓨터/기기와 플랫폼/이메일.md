# 개요

이메일은 인터넷을 통해 전자 문서를 보내고 받는 통신 방식이다. 주소, 제목, 본문, 첨부파일, 수신자와 참조자 정보를 포함하며, 개인 연락부터 업무 기록, 계정 인증, 뉴스레터 발송까지 널리 쓰인다.

이메일은 오래된 기술이지만 여전히 중요한 공식 커뮤니케이션 수단이다. 많은 서비스의 가입, 비밀번호 재설정, 영수증, 공지, 업무 협업이 이메일을 통해 이루어진다.

# 구성

- 보낸 사람과 받는 사람
- 제목
- 본문
- 첨부파일
- 참조와 숨은참조
- 서명
- 스팸·필터·라벨·폴더

# 접근성 관점

이메일 접근성은 문서 접근성과 비슷하다. 제목이 명확해야 하고, 본문 구조가 읽기 쉬워야 하며, 이미지에 필요한 설명이 있어야 한다. 중요한 내용을 이미지나 첨부파일에만 넣으면 보조기술 사용자가 놓칠 수 있다.

뉴스레터나 홍보 메일은 HTML 구조, 링크 문구, 버튼 이름, 색상 대비, 모바일 확대 환경까지 고려해야 한다. 첨부 PDF나 문서도 별도의 접근성 점검이 필요하다.
