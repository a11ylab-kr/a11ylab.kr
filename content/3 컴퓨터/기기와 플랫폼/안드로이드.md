# 개요

미국 Android 사가 첫 삽을 뜨고 현재는 [[Google]]이 개발을 맡고 있는 [[스마트폰]] [[운영 체제]].

# 역사

일찍부터 개발자들에게  [[SDK]]를 배푸하고 활발히 [[앱]]을 만들 수 있는 환경을 마련했다. 물론 처음에는 [[Java]]를 이용했고 이것이 나중에 Java를 인수한 [[Oracle]]과의 다툼으로 이어지기도. 현재는 아예 새로운 개발 언어인 [[Kotlin]]을 만들고 이를 기반으로 [[Android Studio]] 환경에서 개발할 수 있다. 처음에는 [[Eclipse]]라는 Java 진영의 대표적인 [[IDE]]를 사용했다.

### 각 버전 별 이름

Android는 버전 9까지 독특한 이름을 부여했다.

다음은 Android 버전과 그에 해당하는 이름을 나타내는 표입니다:

| 버전 | 이름 |
| --- | --- |
| Android 1.5 | Cupcake |
| Android 1.6 | Donut |
| Android 2.0 - 2.1 | Eclair |
| Android 2.2 | Froyo |
| Android 2.3 | Gingerbread |
| Android 3.0 - 3.2 | Honeycomb |
| Android 4.0 | Ice Cream Sandwich |
| Android 4.1 - 4.3 | Jelly Bean |
| Android 4.4 | KitKat |
| Android 5.0 - 5.1 | Lollipop |
| Android 6.0 | Marshmallow |
| Android 7.0 - 7.1 | Nougat |
| Android 8.0 - 8.1 | Oreo |
| Android 9 | Pie |

Android 9 Pie 이후로는 Android 버전에 특정 이름을 부여하지 않기로 결정하였다.
