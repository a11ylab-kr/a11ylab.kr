# 개요

Windows 10은 [[Microsoft]]가 2015년에 출시한 개인용 컴퓨터 운영체제이다. Windows 8 계열의 타일 중심 인터페이스를 조정하고, 시작 메뉴와 데스크톱 중심 사용 흐름을 다시 강화했다.

# 특징

Windows 10은 장기간 널리 쓰인 Windows 버전으로, 개인용 PC, 업무용 PC, 교육 환경, 보조공학 소프트웨어 실행 환경에서 중요한 위치를 차지했다.

- 시작 메뉴 복귀
- Microsoft Edge 도입
- Windows Hello, 가상 데스크톱, 알림 센터 제공
- 지속 업데이트 방식 강화

# 접근성 관점

Windows 10은 내레이터, 돋보기, 고대비, 음성 인식, 자막, 키보드 접근성 등 여러 보조 기능을 제공한다. 다만 실제 접근성은 운영체제 기능뿐 아니라 앱과 드라이버, 보조공학 소프트웨어 호환성에 따라 달라진다.
