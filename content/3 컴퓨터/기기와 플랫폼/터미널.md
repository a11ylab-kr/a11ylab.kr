# 개요

터미널은 사용자가 글자로 명령을 입력해 컴퓨터와 상호작용하는 환경이다. 그래픽 화면에서 마우스로 조작하는 방식과 달리, 명령어와 출력 텍스트를 중심으로 작업한다.

터미널은 파일 관리, 프로그램 실행, 서버 접속, 개발 도구 사용, 자동화 스크립트 실행에 널리 쓰인다.

# 특징

터미널은 처음에는 어렵게 느껴질 수 있지만, 반복 작업과 자동화에 강하다.

- 명령을 기록하고 재사용하기 쉽다.
- 여러 작업을 스크립트로 묶을 수 있다.
- 원격 서버와 개발 환경을 다루기 좋다.
- 화면보다 텍스트 출력이 중심이라 로그와 오류 추적에 유리하다.

# 접근성 관점

터미널은 텍스트 기반이라 [[화면 읽기 프로그램]]과 잘 맞는 부분이 있지만, 모든 터미널 환경이 자동으로 접근 가능한 것은 아니다. 실시간으로 갱신되는 화면, 색상만으로 표시하는 상태, 복잡한 TUI, 진행률 애니메이션은 읽기 어려울 수 있다.

접근 가능한 CLI 도구를 만들려면 명령 결과를 명확한 텍스트로 출력하고, 오류 메시지를 구체적으로 쓰며, 색상 없이도 의미가 전달되게 해야 한다.
