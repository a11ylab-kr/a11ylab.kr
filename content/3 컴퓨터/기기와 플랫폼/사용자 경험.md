# 개요

사용자 경험은 사용자가 제품, 서비스, 시스템을 만나고 이용하는 전체 경험을 말한다. 줄여서 UX라고 부른다.

# 사용자 인터페이스와의 관계

[[사용자 인터페이스]]가 사용자가 직접 만지는 접점이라면, 사용자 경험은 그 접점을 통해 사용자가 느끼는 이해 가능성, 효율, 신뢰, 만족, 부담까지 포함한다.

# 접근성 관점

접근성은 사용자 경험의 부가 기능이 아니다. 장애가 있는 사용자가 같은 과업을 수행할 수 있는지, 도움 없이 이해할 수 있는지, 실수했을 때 회복할 수 있는지가 사용자 경험의 핵심이다.
