# 개요

PWA 설치 방법은 Progressive Web App을 사용자의 기기 홈 화면이나 앱 목록에 추가해 앱처럼 실행하는 절차를 말한다. PWA는 [[웹]] 기술로 만들어졌지만, 설치 후에는 일반 앱처럼 별도 창에서 실행될 수 있다.

# 일반 절차

브라우저에서 PWA를 지원하는 사이트에 접속하면 주소창이나 메뉴에 “설치”, “앱으로 설치”, “홈 화면에 추가” 같은 항목이 나타난다. 사용자가 이를 선택하면 바로가기와 앱 실행 환경이 만들어진다.

# 접근성 관점

PWA는 웹 접근성을 그대로 이어받는다. 설치가 가능하더라도 키보드 조작, 화면 읽기, 확대, 알림 권한 안내, 오프라인 오류 메시지가 접근 가능해야 한다. 설치 안내도 시각적 아이콘만으로 제공하면 안 된다.
