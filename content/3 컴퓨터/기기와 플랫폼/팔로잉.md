# 개요

팔로잉은 [[SNS]]에서 사용자가 어떤 계정의 게시물이나 활동을 계속 받아보기로 선택한 상태를 말한다. 내가 팔로우한 계정 목록을 팔로잉이라고 부르기도 한다.

# 팔로워와의 차이

팔로잉은 내가 구독하거나 따라가는 대상이고, 팔로워는 나를 구독하거나 따라오는 사람이다. 두 관계는 서로 다를 수 있으며, 플랫폼에 따라 친구 관계처럼 상호 승인이 필요한 경우도 있다.

# 접근성 관점

팔로잉 구조는 사용자가 어떤 정보를 보게 되는지 결정한다. 추천 알고리즘과 알림 설정, 차단·뮤트 기능이 접근 가능해야 사용자가 정보 과부하와 괴롭힘을 스스로 조절할 수 있다.
