# 개요

한글과컴퓨터는 한국의 소프트웨어 기업으로, 문서 작성 프로그램인 [[아래아한글]]과 오피스 제품군으로 잘 알려져 있다.

# 주요 제품

한컴오피스, 한글, 한셀, 한쇼 같은 문서·표·발표 작성 도구를 제공해 왔다. 국내 공공기관과 교육기관 문서 환경에서 오랫동안 중요한 위치를 차지했다.

# 접근성 관점

한글과컴퓨터 제품은 공공문서 접근성과 직접 연결된다. HWP/HWPX 문서가 화면 읽기 프로그램으로 잘 읽히는지, PDF로 변환할 때 구조가 유지되는지, 표와 이미지 대체 텍스트를 제대로 제공할 수 있는지가 중요하다.
