# 개요

ChromeOS는 [[Google]]이 개발한 운영체제로, [[Chrome]] 브라우저와 웹 앱 사용을 중심에 둔 컴퓨팅 환경이다. 주로 [[Chromebook]]에 탑재된다.

초기에는 웹 중심의 가벼운 운영체제로 출발했지만, 현재는 Android 앱, Linux 개발 환경, 기업·교육 관리 기능까지 포함하는 플랫폼으로 확장되었다.

# 특징

- Google 계정과 클라우드 저장소 중심으로 동작한다.
- 자동 업데이트와 샌드박스 구조를 강조한다.
- Chromebook 기기에서 교육·업무용으로 널리 쓰인다.
- 웹 앱, Android 앱, 일부 Linux 앱을 함께 사용할 수 있다.

# 접근성 관점

ChromeOS는 화면 읽기, 확대, 고대비, 자막, 스위치 접근 같은 접근성 기능을 제공한다. 교육 현장에서 Chromebook이 많이 쓰이는 만큼, 접근성 설정과 관리 정책이 학습권에 직접 영향을 준다.
