# 개요

SNS는 Social Network Service의 줄임말로, 사람들이 온라인에서 관계를 맺고 글, 사진, 영상, 링크, 반응을 주고받는 서비스를 말한다. 한국어로는 사회관계망 서비스 또는 소셜 미디어라고도 부른다.

Facebook, Instagram, X, Threads, BlueSky, 카카오톡 채널처럼 개인·단체·기관이 소식을 전하고 대화하는 공간이 여기에 포함된다.

# 특징

SNS는 단순 게시판과 다르게 관계망과 확산 구조를 가진다.

- 팔로우, 친구, 구독 같은 관계 기반 연결
- 좋아요, 공유, 댓글, 인용 같은 반응 기능
- 알고리즘 추천과 타임라인
- 이미지, 영상, 라이브, 짧은 글 등 다양한 형식
- 개인 홍보, 커뮤니티, 뉴스 유통, 고객 응대 기능

# 접근성 관점

SNS 접근성은 플랫폼 기능과 작성자의 습관이 함께 만든다. 플랫폼은 대체 텍스트 입력, 자막, 키보드 접근성, 화면 읽기 호환성을 제공해야 하고, 작성자는 이미지 설명, 명확한 링크 문구, 과도한 이모지·해시태그 사용 자제, 영상 자막 제공을 고려해야 한다.

접근성 연구나 공익 활동에서는 SNS가 빠른 확산 통로가 되지만, 동시에 알고리즘과 폐쇄적 인터페이스에 의존하게 되는 한계도 있다.
