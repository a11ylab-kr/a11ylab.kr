# 개요

Facebook은 Meta가 운영하는 [[SNS]] 플랫폼이다. 개인 프로필, 페이지, 그룹, 이벤트, 메시지, 사진·영상 공유 기능을 제공한다.

# 특징

Facebook은 친구 관계와 그룹, 페이지 기반 커뮤니티를 중심으로 성장했다. 기관 홍보, 지역 커뮤니티, 행사 안내, 시민단체 활동, 광고 운영에도 널리 쓰인다.

# 접근성 관점

Facebook에 게시물을 올릴 때는 이미지의 [[대체 텍스트]], 영상 자막, 명확한 링크 문구, 과도한 이모지 사용 자제 등이 중요하다. 플랫폼이 자동 대체 텍스트를 제공하더라도, 작성자가 직접 설명을 보완하는 편이 더 정확하다.
