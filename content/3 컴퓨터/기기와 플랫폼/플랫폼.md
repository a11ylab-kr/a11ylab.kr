# 개요

플랫폼은 다른 제품, 서비스, 콘텐츠, 사용자가 그 위에서 활동할 수 있도록 기반을 제공하는 환경을 말한다. 컴퓨터 분야에서는 운영체제, 앱 장터, 클라우드, SNS, 개발 생태계처럼 여러 주체가 연결되는 기반을 가리키는 말로 쓰인다.

플랫폼은 단순한 도구보다 넓은 의미를 가진다. 그 위에서 누가 만들고, 누가 배포하고, 누가 접근하고, 어떤 규칙을 따라야 하는지가 함께 정해지기 때문이다.

# 예시

- 운영체제 플랫폼: Windows, macOS, Android, iOS
- 웹 플랫폼: 브라우저, HTML, CSS, JavaScript, 웹 표준
- 클라우드 플랫폼: AWS, Azure, Google Cloud
- 콘텐츠 플랫폼: YouTube, 블로그, 팟캐스트 서비스
- 사회관계망 플랫폼: Facebook, Threads, BlueSky 등
- 개발 플랫폼: GitHub, 앱 스토어, API 생태계

# 접근성 관점

플랫폼의 접근성은 개별 앱 하나보다 더 큰 영향을 준다. 운영체제가 화면 읽기, 확대, 스위치 제어, 음성 입력을 잘 지원하면 그 위의 앱도 접근 가능해질 가능성이 커진다. 반대로 플랫폼 정책이나 기본 컴포넌트가 접근성을 막으면 수많은 서비스가 같은 장벽을 반복한다.

그래서 플랫폼 접근성은 기능 목록보다 생태계의 규칙과 책임 문제에 가깝다. 개발자가 접근 가능한 구성요소를 쉽게 쓰게 하고, 심사와 문서, API, 고객 지원까지 접근성을 포함해야 한다.
