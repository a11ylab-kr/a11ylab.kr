# 개요

Microsoft Edge는 [[Microsoft]]가 제공하는 웹 브라우저이다. 현재 Edge는 Chromium 기반으로 개발되며, Windows와 Microsoft 365 생태계와 깊게 연결되어 있다.

# 특징

웹 브라우징, PDF 보기, 확장 프로그램, 개발자 도구, 동기화, 보안 기능을 제공한다. Windows 기본 브라우저로 제공되는 경우가 많고, 기업 관리 정책과도 잘 연결된다.

# 접근성 관점

Edge는 [[웹 접근성]] 테스트와 실제 사용자 환경 모두에서 중요하다. 브라우저가 HTML, ARIA, 키보드 초점, PDF 보기, 확대, 고대비 모드, 화면 읽기 프로그램과 어떻게 상호작용하는지가 접근성 품질에 영향을 준다.

웹 개발자는 Chrome뿐 아니라 Edge, Firefox, Safari 등 여러 브라우저와 보조기술 조합에서 확인해야 한다.
