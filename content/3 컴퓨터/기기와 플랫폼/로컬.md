# 개요

로컬은 사용자의 기기나 현재 작업 중인 컴퓨터 안에서 직접 실행·저장되는 환경을 말한다. 반대 개념으로는 원격, 클라우드, 서버 환경을 들 수 있다.

# 예시

로컬 파일은 내 컴퓨터 저장장치에 있는 파일이고, 로컬 서버는 내 컴퓨터에서 실행되는 테스트용 서버이다. 로컬 모델은 외부 API가 아니라 내 기기에서 직접 실행되는 인공지능 모델을 뜻할 수 있다.

# 접근성 관점

로컬 환경은 네트워크가 불안정해도 쓸 수 있고, 민감한 데이터를 외부로 보내지 않아도 되는 장점이 있다. 반면 설치와 설정, 업데이트, 성능 요구사항을 사용자가 직접 감당해야 할 수 있다.

보조공학과 AI 접근성 기능에서는 로컬 처리와 클라우드 처리의 균형이 중요하다.
