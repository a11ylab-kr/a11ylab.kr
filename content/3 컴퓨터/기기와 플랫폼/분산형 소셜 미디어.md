# 개요

분산형 소셜 미디어는 하나의 중앙 플랫폼이 모든 계정과 게시물을 통제하지 않고, 여러 서버나 서비스가 서로 연결되어 동작하는 소셜 미디어 구조를 말한다.

# 특징

분산형 구조에서는 사용자가 특정 서버에 가입해도 다른 서버 사용자와 소통할 수 있다. 서버 운영 정책, 데이터 이동성, 알고리즘 선택권, 커뮤니티 자율성을 중요하게 본다. Mastodon, BlueSky 같은 서비스가 이 논의에서 자주 언급된다.

# 접근성 관점

분산형이라고 해서 자동으로 접근 가능한 것은 아니다. 각 클라이언트와 서버가 대체 텍스트, 키보드 조작, 화면 읽기 호환성, 신고·차단 기능을 잘 제공해야 한다. 접근성 좋은 클라이언트가 선택지로 존재하는 것은 장점이지만, 서버마다 경험이 달라질 수 있다.
