# 개요

바탕 화면은 운영체제에서 사용자가 파일, 폴더, 앱 바로가기, 창을 배치하고 작업을 시작하는 기본 화면이다. 영어로는 desktop이라고 부른다.

# 특징

그래픽 사용자 인터페이스에서는 바탕 화면이 실제 책상처럼 비유된다. 사용자는 창을 열고 닫고, 파일을 끌어다 놓고, 작업 표시줄이나 Dock을 통해 앱을 전환한다.

# 접근성 관점

바탕 화면의 접근성은 키보드 탐색, 초점 표시, 아이콘 이름, 화면 확대, 화면 읽기 프로그램의 창 읽기 방식과 연결된다. 아이콘 위치만 기억하게 만드는 환경은 시각장애인 사용자에게 불리할 수 있다.
