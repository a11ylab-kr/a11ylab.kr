# 개요

GIGO는 Garbage In, Garbage Out의 줄임말로, 잘못된 입력을 넣으면 잘못된 출력이 나온다는 뜻이다. 컴퓨터와 데이터 처리, 인공지능, 통계 분석에서 자주 쓰이는 표현이다.

# 의미

시스템이 아무리 정교해도 입력 데이터가 부정확하거나 편향되어 있으면 결과도 신뢰하기 어렵다. 데이터 품질, 전처리, 검증, 맥락 이해가 중요한 이유를 설명할 때 쓰인다.

# 접근성 관점

접근성 데이터에서도 GIGO는 중요하다. 잘못된 대체 텍스트, 부정확한 자막, 누락된 사용자 피드백, 편향된 테스트 환경을 바탕으로 자동 평가를 하면 실제 접근성 문제를 놓칠 수 있다.
