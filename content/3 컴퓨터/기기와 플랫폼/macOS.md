# 개요

macOS는 Apple의 [[Mac]] 컴퓨터에서 사용하는 운영체제이다. 그래픽 사용자 인터페이스, 파일 관리, 앱 실행, 보안, iCloud와 Apple 기기 연동 기능을 제공한다.

# 특징

macOS는 Unix 계열 기반을 갖고 있어 [[터미널]]과 개발 도구 사용에도 강점이 있다. 동시에 Finder, Dock, 메뉴 막대 같은 그래픽 인터페이스를 통해 일반 사용자 작업을 지원한다.

# 접근성 관점

macOS에는 VoiceOver, 확대/축소, 디스플레이 조정, 음성 명령, 스위치 제어, 실시간 자막, 키보드 접근성 기능이 포함되어 있다. 특히 VoiceOver는 별도 구매 없이 사용할 수 있는 기본 화면 읽기 프로그램이라는 점에서 중요하다.

앱 개발과 문서 제작에서도 macOS의 접근성 API와 VoiceOver 호환성을 확인해야 한다.
