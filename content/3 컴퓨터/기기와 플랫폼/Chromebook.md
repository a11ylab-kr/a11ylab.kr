# 개요

Chromebook은 [[ChromeOS]]를 탑재한 노트북 또는 태블릿형 컴퓨터이다. 웹 브라우저와 클라우드 서비스를 중심으로 사용하며, 교육 현장에서 많이 보급되었다.

# 특징

Chromebook은 빠른 부팅, 자동 업데이트, Google 계정 연동, 웹 앱 사용, 관리 편의성을 강조한다. 모델에 따라 Android 앱과 Linux 개발 환경도 지원한다.

# 접근성 관점

Chromebook은 교육 접근성과 직접 연결된다. ChromeVox, 확대, 고대비, 선택하여 말하기, 스위치 접근, 자막 같은 기능을 제공하지만, 학교 관리 정책이 접근성 설정을 막지 않는지도 중요하다.

학생이 자기에게 맞는 접근성 기능을 켜고 유지할 수 있어야 하며, 교사와 관리자도 기본 기능을 알고 있어야 한다.
