# 개요

음성 합성 장치는 글자나 데이터를 사람이 들을 수 있는 음성으로 바꾸는 장치 또는 소프트웨어이다. 흔히 TTS, 곧 text-to-speech라고 부른다.

초기에는 별도의 하드웨어 장치로 제공되는 경우가 많았지만, 지금은 운영체제와 앱 안에 내장된 음성 합성 엔진으로 쓰이는 경우가 많다.

# 쓰임

음성 합성은 여러 접근성 기능의 기반이 된다.

- [[화면 읽기 프로그램]]이 화면의 텍스트와 조작 정보를 읽어 준다.
- 전자책, 문서, 웹페이지를 음성으로 들을 수 있게 한다.
- 내비게이션, 안내 방송, 키오스크, 스마트 스피커가 정보를 음성으로 제공한다.
- 말하기가 어려운 사용자가 보완대체의사소통 장치에서 문장을 입력해 음성으로 출력한다.

# 접근성 관점

음성 합성의 품질은 단순히 목소리가 자연스러운지에만 달려 있지 않다. 발음, 속도 조절, 언어 전환, 숫자·기호·약어 읽기, 문장 부호 처리, 긴 문서에서의 피로도, 사용자 설정 가능성이 함께 중요하다.

한국어 환경에서는 한자어, 영어 약어, 숫자와 단위, 외래어, 이모지, 점자·수식 표현을 어떻게 읽는지도 접근성 품질에 큰 영향을 준다.
