# 개요

Windows CE는 [[Microsoft]]가 임베디드 기기와 휴대용 장치를 위해 만든 운영체제 계열이다. PDA, 산업용 단말기, 내비게이션, 일부 휴대용 컴퓨터에서 사용되었다.

# 특징

데스크톱 Windows와 이름은 비슷하지만, 작은 장치와 제한된 자원에 맞춰 설계된 별도 계열이다. 이후 Windows Embedded Compact라는 이름으로도 이어졌다.

# 접근성 관점

Windows CE 기반 기기는 키오스크, 단말기, 산업 장비처럼 특정 목적 장치로 쓰이는 경우가 많았다. 이런 장치의 접근성은 운영체제보다 실제 제품의 버튼, 음성 안내, 화면 확대, 외부 입력 지원에 크게 좌우된다.
