# 개요

Windows Vista는 [[Microsoft]]가 2007년에 출시한 [[Windows]] 운영체제이다. Windows XP 이후 등장했으며, 보안 구조와 그래픽 인터페이스, 검색 기능을 크게 바꾸려 한 버전이다.

# 특징

Aero 인터페이스, 사용자 계정 컨트롤, 강화된 검색, 새로운 드라이버 모델이 도입되었다. 다만 높은 시스템 요구사항과 호환성 문제 때문에 평가가 엇갈렸다.

# 접근성 관점

Vista 시기에는 Windows 접근성 기능과 보조공학 소프트웨어 호환성이 함께 중요한 이슈였다. 운영체제 구조가 바뀌면 화면 읽기 프로그램, 확대 프로그램, 점자 장치 드라이버도 영향을 받는다.
