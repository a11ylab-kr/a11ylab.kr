# 개요

MSX 색상표는 MSX 컴퓨터에서 그래픽을 표시할 때 사용할 수 있는 기본 색상 체계를 말한다. MSX는 1980년대 가정용 컴퓨터 표준 중 하나였고, 제한된 색상과 해상도 안에서 게임과 교육용 소프트웨어가 만들어졌다.

# 의미

색상표는 당시 하드웨어의 표현 한계를 보여 준다. 적은 색상만으로 캐릭터, 배경, 글자를 구분해야 했기 때문에 픽셀 아트와 게임 그래픽 디자인에서 색 선택이 중요했다.

# 접근성 관점

제한된 색상표 환경에서는 색상 대비와 패턴 구분이 특히 중요하다. 색만으로 정보를 구분하면 색각 이상 사용자나 저시력 사용자가 정보를 놓칠 수 있다.
