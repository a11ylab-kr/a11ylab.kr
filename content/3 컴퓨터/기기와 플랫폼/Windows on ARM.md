# 개요

Windows on ARM은 ARM 계열 프로세서에서 실행되는 [[Windows]] 환경을 말한다. 전통적인 Windows PC가 주로 x86/x64 프로세서를 사용해 온 것과 달리, 저전력·고효율 ARM 칩을 쓰는 기기에서 Windows를 구동한다.

# 특징

- 배터리 효율과 휴대성을 강조한다.
- 일부 x86/x64 앱은 에뮬레이션으로 실행된다.
- 드라이버와 보조공학 소프트웨어 호환성이 중요한 변수이다.
- Qualcomm Snapdragon 계열 칩을 쓰는 Windows 노트북에서 많이 논의된다.

# 접근성 관점

Windows on ARM의 접근성은 보조공학 프로그램과 주변기기 드라이버가 ARM 환경에서 잘 동작하는지에 달려 있다. 화면 읽기 프로그램, 점자 표시 장치, OCR, 확대 프로그램처럼 시스템 깊숙이 연결되는 도구는 호환성 확인이 특히 중요하다.
