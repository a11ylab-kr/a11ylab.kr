# 개요

Windows 95는 [[Microsoft]]가 1995년에 출시한 개인용 컴퓨터 운영체제이다. 시작 버튼과 작업 표시줄, 데스크톱 중심 인터페이스를 대중화한 버전으로 기억된다.

# 의미

Windows 95는 DOS 기반 사용 흐름에서 그래픽 사용자 인터페이스 중심의 개인용 컴퓨팅으로 넘어가는 전환점이었다. Plug and Play, 긴 파일 이름, 32비트 응용 프로그램 지원 등이 강조되었다.

# 접근성 관점

Windows 95 시기의 접근성은 오늘날과 비교하면 제한적이었지만, 개인용 컴퓨터가 널리 보급되며 화면 읽기 프로그램과 확대 프로그램 같은 보조공학 소프트웨어가 함께 성장하는 기반이 되었다.
