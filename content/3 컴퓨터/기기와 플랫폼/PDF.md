# 개요

PDF는 Portable Document Format의 줄임말로, 운영체제나 프로그램이 달라도 문서의 모양을 비교적 일정하게 보존하기 위해 만들어진 파일 형식이다. 공문서, 논문, 안내문, 보고서, 신청서 배포에 널리 쓰인다.

PDF는 인쇄 결과를 고정하는 데 강하지만, 접근성 측면에서는 문서 구조가 제대로 들어 있는지가 중요하다.

# 접근성 관점

접근 가능한 PDF에는 제목, 문단, 목록, 표, 이미지 설명, 읽기 순서 같은 구조 정보가 포함되어야 한다. 스캔 이미지로만 된 PDF는 [[화면 읽기 프로그램]]이 내용을 읽기 어렵기 때문에 OCR과 구조 보정이 필요하다.

공공기관 자료에서 PDF만 제공하면 모바일 사용자, 저시력 사용자, 화면 읽기 프로그램 사용자에게 장벽이 될 수 있다. 가능하다면 HTML 본문, 접근 가능한 Word 문서, 텍스트 파일을 함께 제공하는 편이 좋다.
