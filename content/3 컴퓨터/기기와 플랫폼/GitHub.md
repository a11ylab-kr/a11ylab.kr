# 개요

주로 개발자들이 프로그램의 소스 코드를 저장하고 개정 이력을 관리하거나 협업하기 위해 사용하는 저장소이다. 이 저장소에 올려진 소스 코드는 일반적으로 대중에게 공개되므로 [[오픈 소스]] 생태계의 중요한 지점이 된다.  [[인공지능]]이 코드를 생성하고 쉽게 저장소를 읽고 쓸 수 있게 되면서 비개발자에게도 중요한 공간이 되었다.
