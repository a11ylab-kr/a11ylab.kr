# 개요

GitHub는 Git 저장소를 웹에서 호스팅하고 협업할 수 있게 해 주는 개발 플랫폼이다. 코드 저장, 이슈 관리, Pull Request, Wiki, Actions 자동화, 릴리스 배포 기능을 제공한다.

# 특징

개발자는 GitHub를 통해 변경 이력을 관리하고, 여러 사람이 코드 리뷰와 배포 과정을 함께 진행할 수 있다. 오픈소스 프로젝트의 공개 협업 공간으로도 널리 쓰인다.

# 접근성 관점

GitHub는 개발 도구인 동시에 웹 플랫폼이다. 이슈, 코드 리뷰, Actions 로그, 문서가 보조기술로 접근 가능해야 장애가 있는 개발자도 협업에 참여할 수 있다. 프로젝트 문서에서도 접근성 지침과 테스트 절차를 함께 관리하는 것이 좋다.
