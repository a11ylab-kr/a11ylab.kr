# 개요

Chrome은 [[Google]]이 개발한 웹 브라우저이다. [[웹]] 페이지를 표시하고, 웹 앱을 실행하며, 확장 프로그램과 개발자 도구를 제공한다.

# 특징

Chrome은 빠른 JavaScript 실행, 자동 업데이트, 확장 프로그램 생태계, Google 계정 동기화를 특징으로 한다. Chromium 오픈소스 프로젝트를 기반으로 하며, 여러 브라우저가 Chromium 계열 기술을 공유한다.

# 접근성 관점

브라우저 접근성은 [[웹 접근성]]의 실제 사용 환경을 좌우한다. Chrome은 운영체제의 화면 읽기 프로그램, 확대, 키보드 탐색, 개발자 도구와 함께 웹 접근성 검사와 디버깅에 자주 쓰인다.
