# 개요

`slmgr`은 Windows의 소프트웨어 라이선스 관리 명령 도구이다. 정식 이름은 Software Licensing Management Tool이며, 보통 명령 프롬프트나 PowerShell에서 실행한다.

# 쓰임

Windows 제품 키 확인, 라이선스 상태 조회, 정품 인증 관련 작업, KMS 서버 설정 같은 관리 작업에 쓰인다.

# 주의할 점

라이선스 명령은 시스템 상태를 바꿀 수 있으므로 출처가 불분명한 명령을 그대로 실행하면 안 된다. 기관이나 학교 장비에서는 관리자 정책과 정품 인증 체계를 확인해야 한다.
