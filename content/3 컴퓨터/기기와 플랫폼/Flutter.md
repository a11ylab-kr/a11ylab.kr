# 개요

Flutter는 [[Google]]이 만든 오픈소스 UI 프레임워크이다. 하나의 코드베이스로 Android, iOS, 웹, 데스크톱 앱을 만들 수 있도록 설계되었다.

# 특징

Flutter는 Dart 언어와 위젯 기반 구조를 사용한다. 화면 요소를 조합해 앱을 만들고, 빠른 개발 반복과 일관된 UI 표현을 장점으로 내세운다.

# 접근성 관점

Flutter 앱도 플랫폼 접근성 API와 잘 연결되어야 한다. 버튼 이름, 초점 순서, 의미 레이블, 텍스트 크기 조절, 화면 읽기 지원을 확인해야 하며, 커스텀 위젯을 만들 때 접근성 정보가 빠지기 쉽다.
