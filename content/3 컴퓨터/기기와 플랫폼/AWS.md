# 개요

AWS는 Amazon Web Services의 줄임말로, Amazon이 제공하는 클라우드 컴퓨팅 플랫폼이다. 서버, 저장소, 데이터베이스, 네트워크, 인공지능, 보안, 배포 도구를 인터넷을 통해 제공한다.

# 특징

AWS는 EC2, S3, RDS, Lambda 같은 다양한 서비스를 제공하며, 스타트업부터 대기업, 공공기관까지 넓게 사용된다. 사용량 기반 과금과 자동 확장, 글로벌 리전이 주요 특징이다.

# 접근성 관점

클라우드 플랫폼은 관리 콘솔, 문서, API, 교육 자료의 접근성이 중요하다. 장애가 있는 개발자와 운영자도 서버를 배포하고 장애를 대응하고 로그를 읽을 수 있어야 한다.

또한 AWS 위에서 제공되는 서비스도 접근성 책임을 가진다. 인프라가 클라우드라고 해서 사용자-facing 접근성이 자동으로 해결되지는 않는다.
