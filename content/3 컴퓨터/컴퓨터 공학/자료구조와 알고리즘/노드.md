# 개요

노드는 자료구조에서 하나의 데이터 단위 또는 연결 지점을 말한다. 연결 리스트, 트리, 그래프 같은 구조에서 노드는 값을 담거나 다른 노드와의 관계를 가진다.

# 예시

트리에서는 각 항목이 노드이며, 위아래 관계를 부모 노드와 자식 노드라고 부른다. 그래프에서는 사람, 장소, 페이지 같은 대상이 노드가 되고, 관계나 연결이 간선이 된다.

# 의미

노드는 데이터를 단순한 표가 아니라 관계 구조로 이해할 때 중요한 개념이다. 웹의 링크, 파일 구조, 지식 그래프, 네트워크 분석에서도 노드 개념을 사용한다.
