# 개요

LaTeX는 문서의 구조와 수식 표현을 명령어로 작성해 고품질 조판 결과를 만드는 문서 작성 시스템이다. 논문, 수학·과학 문서, 기술 보고서, 책, 발표 자료 제작에 널리 쓰인다.

일반 워드프로세서가 화면에 보이는 모양을 직접 편집하는 방식에 가깝다면, LaTeX는 제목, 절, 수식, 표, 참고문헌 같은 구조를 표시하고 컴파일을 통해 결과 문서를 만든다.

# 특징

LaTeX의 장점은 복잡한 문서 구조를 안정적으로 다루는 데 있다.

- 수식 조판이 강하다.
- 장·절 번호, 그림·표 번호, 목차, 참고문헌을 자동 관리하기 쉽다.
- 긴 문서와 공동 작업에서 구조 일관성을 유지하기 좋다.
- 텍스트 기반이라 버전 관리와 자동화에 잘 맞는다.

반면 명령어와 컴파일 오류에 익숙해져야 하고, 시각적으로 즉시 편집하는 방식에 익숙한 사용자에게는 진입 장벽이 있다.

# 접근성 관점

LaTeX 문서는 결과물이 PDF로 배포되는 경우가 많다. 이때 PDF 접근성을 따로 고려하지 않으면 제목 구조, 읽기 순서, 수식 대체 설명, 표 구조, 태그 정보가 부족해질 수 있다.

수식이 많은 문서는 특히 접근성 점검이 중요하다. 수식을 이미지로만 넣으면 [[화면 읽기 프로그램]] 사용자가 내용을 읽기 어렵다. MathML, 구조화된 PDF, 원본 `.tex` 파일 제공, HTML 변환 등 여러 접근 경로를 함께 고려해야 한다.
