# 개요

게슈탈트 원리는 사람이 시각 정보를 낱낱의 요소가 아니라 일정한 관계와 패턴으로 묶어 지각한다는 심리학적 원리이다. 디자인과 사용자 인터페이스에서는 화면 요소를 어떻게 배치해야 사용자가 구조를 빠르게 이해할 수 있는지 설명할 때 자주 쓰인다.

# 주요 원리

- 근접성: 가까이 있는 요소를 같은 그룹으로 본다.
- 유사성: 모양, 색, 크기가 비슷한 요소를 같은 종류로 본다.
- 연속성: 선이나 흐름이 이어지는 방향으로 정보를 이해한다.
- 폐쇄성: 일부가 비어 있어도 익숙한 형태로 완성해 본다.
- 전경과 배경: 어떤 요소를 주된 대상으로, 나머지를 배경으로 구분한다.

# 접근성 관점

게슈탈트 원리는 시각적 이해를 돕지만, 시각적 묶음만으로 의미를 전달하면 접근성 장벽이 된다. 화면 읽기 프로그램 사용자는 색, 위치, 거리만으로 만들어진 관계를 그대로 알기 어렵다. 따라서 시각적 그룹은 제목, 목록, 영역, 레이블 같은 구조 정보로도 함께 표현되어야 한다.
