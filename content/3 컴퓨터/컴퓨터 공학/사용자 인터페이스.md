# 개요

사용자 인터페이스는 사람이 [[컴퓨터]], 소프트웨어, 기기, 서비스와 상호작용하는 접점을 말한다. 줄여서 UI라고 부른다.

버튼, 메뉴, 화면 구성, 키보드 단축키, 음성 명령, 진동, 알림음, 점자 출력처럼 사용자가 시스템의 상태를 알고 명령을 전달하는 모든 통로가 사용자 인터페이스가 될 수 있다.

# 구성 요소

사용자 인터페이스는 보통 입력과 출력이 함께 이루어지는 구조이다.

- 입력: 키보드, 마우스, 터치, 음성, 스위치, 센서, 점자 키 등 사용자의 명령을 받는 부분
- 출력: 화면, 소리, 진동, [[점자 표시 장치]], 알림 등 시스템 상태를 알려 주는 부분
- 피드백: 사용자의 행동이 시스템에 전달되었는지 확인하게 해 주는 반응
- 구조: 사용자가 기능을 찾고 순서를 이해할 수 있게 돕는 메뉴, 제목, 영역, 흐름

# 접근성 관점

접근성에서 사용자 인터페이스는 “보이는 화면”만을 뜻하지 않는다. 화면을 볼 수 없는 사용자, 마우스를 쓰기 어려운 사용자, 복잡한 절차를 이해하기 어려운 사용자도 같은 기능에 접근할 수 있어야 한다.

좋은 사용자 인터페이스는 여러 입력·출력 방식을 허용한다. 키보드만으로 조작할 수 있고, [[화면 읽기 프로그램]]이 구조를 읽을 수 있으며, 확대해도 흐름이 깨지지 않고, 오류가 났을 때 사용자가 원인을 이해할 수 있어야 한다.
