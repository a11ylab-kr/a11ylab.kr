# 개요

입력 장치는 사용자가 [[컴퓨터]]나 디지털 기기에 [[자료]], 명령, 신호를 전달하는 장치이다. 키보드, 마우스, 터치스크린, 마이크, 카메라, 스캐너, 게임 컨트롤러, 스위치, 센서 등이 여기에 포함된다.

입력 장치는 사람이 기계에게 “무엇을 하라”고 전달하는 통로이다. 그래서 입력 장치의 형태는 사용자의 몸, 환경, 과업, 장애 특성에 따라 달라져야 한다.

# 종류

입력 장치는 입력 방식에 따라 나눌 수 있다.

- 문자 입력: [[키보드]], 점자 키보드, 음성 입력
- 위치 입력: 마우스, 트랙패드, 터치스크린, 조이스틱
- 감각 입력: 마이크, 카메라, 스캐너
- 대체 입력: 스위치, 시선 추적 장치, 헤드 마우스, 보조 버튼
- 환경 입력: 온도·거리·빛·압력 센서 등

[[피지컬 컴퓨팅]]에서는 센서가 주변 환경의 변화를 읽어 입력 장치 역할을 한다.

# 접근성 관점

접근성에서 중요한 것은 하나의 입력 장치를 모두에게 강제하지 않는 것이다. 마우스만으로 조작할 수 있는 인터페이스는 키보드 사용자에게 장벽이 되고, 터치 제스처만 제공하는 앱은 손동작이 어려운 사용자에게 장벽이 된다.

따라서 서비스와 기기는 가능한 한 여러 입력 방식을 지원해야 한다. 키보드 접근성, 음성 입력, 스위치 제어, 점자 입력, 단축키, 외부 보조기기 연결성은 모두 사용자 선택권과 관련된다.
