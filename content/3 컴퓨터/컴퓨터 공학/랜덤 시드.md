# 개요

랜덤 시드는 난수 생성기의 출발값이다. 컴퓨터의 난수는 대개 완전히 무작위가 아니라 알고리즘으로 만들어지므로, 같은 시드를 넣으면 같은 난수열이 다시 나온다.

# 쓰임

랜덤 시드는 실험 재현, 게임 맵 생성, 데이터 셔플, 머신러닝 학습, 테스트 자동화에서 중요하다. 같은 조건을 다시 만들 수 있어 오류 추적과 결과 비교가 쉬워진다.

# 주의할 점

보안이 필요한 암호학적 난수에는 예측 가능한 시드를 쓰면 안 된다. 재현 가능한 실험용 난수와 보안용 난수는 목적이 다르다.
