# 개요

pywin32는 Python에서 Windows API와 COM 기능을 사용할 수 있게 해 주는 확장 패키지이다. Windows 전용 자동화, 시스템 관리, Office 자동화, 데스크톱 앱 제어에 쓰인다.

# 쓰임

Python 스크립트에서 파일 속성, 레지스트리, 창 제어, COM 객체, Microsoft Office 자동화, Windows 서비스 관련 기능을 다룰 때 사용한다.

# 접근성 관점

pywin32는 Windows 자동화와 접근성 테스트 보조 작업에 활용될 수 있다. 다만 UI 자동화나 보조기술 제어는 사용자 환경에 직접 영향을 줄 수 있으므로, 권한과 안전성을 확인해야 한다.

화면 읽기 프로그램, 키보드 조작, 포커스 이동을 자동화할 때는 사용자의 실제 입력을 방해하지 않도록 주의해야 한다.
