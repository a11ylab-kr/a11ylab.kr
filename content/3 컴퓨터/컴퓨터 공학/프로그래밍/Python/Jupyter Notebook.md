# 개요

Jupyter Notebook은 코드, 실행 결과, 설명 문장, 표, 그래프를 한 문서 안에 함께 담을 수 있는 대화형 계산 문서 형식이다. Python 데이터 분석과 교육에서 특히 많이 쓰인다.

# 특징

셀 단위로 코드를 실행하고 결과를 바로 확인할 수 있다. 분석 과정, 실험 기록, 시각화, 설명을 함께 남길 수 있어 재현 가능한 연구와 교육 자료 제작에 유용하다.

# 접근성 관점

노트북은 코드 셀, 출력, 그래프, 수식이 섞여 있어 접근성이 복잡하다. 그래프에는 텍스트 설명과 데이터 표를 함께 제공하고, 실행 순서가 꼬이지 않게 정리해야 한다. 화면 읽기 프로그램 사용자는 셀 구조와 출력 영역 탐색이 어려울 수 있다.
