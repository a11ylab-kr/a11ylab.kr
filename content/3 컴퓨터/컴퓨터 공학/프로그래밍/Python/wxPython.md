# 개요

wxPython은 Python에서 데스크톱 그래픽 사용자 인터페이스를 만들기 위한 라이브러리이다. C++ GUI 툴킷인 wxWidgets를 Python에서 사용할 수 있게 한다.

# 특징

Windows, macOS, Linux에서 네이티브에 가까운 위젯을 사용해 창, 버튼, 메뉴, 대화상자 같은 데스크톱 앱 UI를 만들 수 있다.

# 접근성 관점

데스크톱 GUI를 만들 때는 운영체제의 접근성 API와 위젯 의미가 잘 연결되어야 한다. 버튼 이름, 키보드 탐색, 초점 순서, 오류 메시지, 화면 읽기 프로그램 호환성을 확인해야 한다.
