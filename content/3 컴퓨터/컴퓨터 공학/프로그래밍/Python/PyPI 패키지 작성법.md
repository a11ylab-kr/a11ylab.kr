# 개요

PyPI 패키지 작성법은 Python 코드를 다른 사람이 설치해 쓸 수 있는 패키지 형태로 구성하고, 필요하면 [[PyPI]]에 배포하는 절차를 말한다.

# 기본 흐름

1. 패키지 이름과 폴더 구조를 정한다.
2. `pyproject.toml`에 메타데이터와 빌드 설정을 쓴다.
3. README, 라이선스, 버전 정보를 준비한다.
4. 테스트를 실행한다.
5. 빌드 도구로 배포 파일을 만든다.
6. TestPyPI나 PyPI에 업로드한다.

# 접근성 관점

CLI 패키지를 만들 때는 도움말, 오류 메시지, 진행 상황 출력이 읽기 쉬워야 한다. 문서도 Markdown이나 HTML로 접근 가능하게 제공하고, 예제 코드는 복사하기 쉽게 정리하는 것이 좋다.
