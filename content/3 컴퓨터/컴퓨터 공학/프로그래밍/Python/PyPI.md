# 개요

PyPI는 Python Package Index의 줄임말로, Python 패키지를 배포하고 설치할 수 있는 공식 패키지 저장소이다.

# 쓰임

개발자는 PyPI에 패키지를 올리고, 사용자는 `pip install 패키지명` 명령으로 패키지를 설치한다. 데이터 분석, 웹 개발, 자동화, 문서 처리 등 Python 생태계의 많은 도구가 PyPI를 통해 배포된다.

# 주의할 점

패키지는 누구나 배포할 수 있으므로 이름이 비슷한 악성 패키지, 오래 관리되지 않는 패키지, 의존성 문제를 확인해야 한다. 업무 환경에서는 버전 고정과 가상환경 사용이 중요하다.
