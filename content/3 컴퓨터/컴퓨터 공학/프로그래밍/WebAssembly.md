# 개요

WebAssembly(줄여서 Wasm)는 최신 웹 브라우저에서 실행할 수 있는 새로운 유형의 코드이다. 네이티브에 가까운 성능으로 실행되는 바이너리 형식의 명령 집합으로, [[C]], C++, [[Rust]]와 같은 저수준 언어를 웹에서 실행할 수 있게 해주는 컴파일 대상(Compilation Target)이다. JavaScript와 함께 실행되면서도 JavaScript보다 훨씬 빠른 연산 속도를 제공하여 고성능 애플리케이션(영상 편집, 게임, 3D 렌더링 등)을 웹 브라우저상에서 원활하게 구동할 수 있도록 돕는 기술이다.
