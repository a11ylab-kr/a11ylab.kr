# 개요

C#은 [[Microsoft]]가 만든 객체지향 프로그래밍 언어이다. .NET 플랫폼과 함께 웹, 데스크톱, 서버, 게임, 모바일 앱 개발에 쓰인다.

# 특징

C#은 정적 타입 언어이며, 클래스, 인터페이스, 제네릭, 비동기 프로그래밍 같은 기능을 제공한다. Unity 게임 개발과 Windows 앱 개발에서도 많이 쓰인다.

# 접근성 관점

C#으로 데스크톱이나 웹 앱을 만들 때는 플랫폼 접근성 API, 키보드 조작, 화면 읽기 프로그램 호환성, 명확한 오류 메시지를 함께 고려해야 한다.
