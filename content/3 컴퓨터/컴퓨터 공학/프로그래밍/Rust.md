# 개요

Rust는 안정성과 성능, 동시성을 중시하는 시스템 프로그래밍 언어이다. 메모리 안전성을 컴파일 단계에서 강하게 검사하면서도, 가비지 컬렉터 없이 빠른 실행 성능을 목표로 한다.

# 특징

Rust는 소유권과 빌림 규칙을 통해 메모리 오류를 줄인다. C와 C++이 쓰이던 영역, 서버, CLI 도구, 웹어셈블리, 임베디드, 운영체제 구성요소 개발에서 자주 논의된다.

# 접근성 관점

Rust 자체가 접근성 기술은 아니지만, 안정적인 시스템 소프트웨어와 도구를 만드는 데 쓰일 수 있다. CLI 도구를 Rust로 만들 때도 출력 구조, 오류 메시지, 색상 의존성, 키보드 조작성을 고려해야 한다.
