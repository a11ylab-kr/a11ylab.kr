# 개요

API는 Application Programming Interface의 줄임말로, 프로그램과 프로그램이 서로 기능이나 데이터를 주고받기 위해 정해 둔 약속이다. 사람이 화면을 눌러 서비스를 쓰는 것처럼, 프로그램은 API를 통해 다른 프로그램의 기능을 호출한다.

# 예시

날씨 앱은 기상 데이터 API를 호출해 현재 날씨를 가져올 수 있다. 지도 앱은 경로 탐색 API를 사용하고, 결제 서비스는 결제 승인 API를 제공한다. 웹서비스에서는 HTTP 요청과 JSON 응답 형태의 API가 흔히 쓰인다.

# 접근성 관점

API는 접근성 기능을 가능하게 하는 기반이 될 수 있다. 예를 들어 이미지 대체 텍스트, 자막, 문서 구조, 사용자 접근성 설정을 API에서 제공하면 여러 앱과 서비스가 같은 접근성 정보를 활용할 수 있다.

반대로 API가 접근성 관련 데이터를 제공하지 않으면, 화면에는 정보가 있어도 보조기술이나 외부 도구가 그 정보를 활용하기 어렵다.
