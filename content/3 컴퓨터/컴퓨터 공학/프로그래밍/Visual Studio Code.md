# 개요

Visual Studio Code는 [[Microsoft]]가 만든 코드 편집기이다. Windows, macOS, Linux에서 사용할 수 있으며, 확장 프로그램을 통해 다양한 언어와 개발 도구를 지원한다.

# 특징

VS Code는 가볍게 시작할 수 있으면서도 디버깅, Git 연동, 터미널, 원격 개발, 확장 프로그램 생태계를 갖추고 있다. Python, JavaScript, Markdown, Rust 등 여러 작업에 널리 쓰인다.

# 접근성 관점

코드 편집기는 키보드 조작과 화면 읽기 지원이 중요하다. VS Code는 스크린 리더 모드와 접근성 관련 설정을 제공하지만, 확장 프로그램이나 터미널 출력, 자동완성 UI가 접근성에 영향을 줄 수 있다.
