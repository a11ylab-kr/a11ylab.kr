# 개요

Hello World는 새 프로그래밍 언어나 개발 환경을 처음 배울 때 화면에 “Hello, World!” 같은 짧은 문장을 출력해 보는 예제이다.

# 의미

이 예제는 문법 전체를 설명하기보다, 개발 도구가 제대로 설치되었는지, 코드를 작성하고 실행하는 흐름이 작동하는지 확인하는 첫 단계로 쓰인다.

# 접근성 관점

처음 배우는 예제도 접근 가능해야 한다. 개발 환경 설치, 터미널 출력, 오류 메시지, 강의 자료가 화면 읽기 프로그램과 키보드 조작으로 따라갈 수 있어야 한다.
