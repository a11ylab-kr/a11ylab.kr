# 개요

R은 통계 분석과 데이터 시각화에 널리 쓰이는 프로그래밍 언어이자 실행 환경이다. 연구, 데이터 분석, 교육, 통계 모델링에서 많이 사용된다.

# 특징

R은 데이터프레임, 통계 함수, 그래프 작성 패키지 생태계가 강하다. CRAN을 통해 다양한 패키지를 설치할 수 있고, R Markdown이나 Quarto와 함께 재현 가능한 보고서를 만들 수 있다.

# 접근성 관점

R로 만든 그래프와 보고서는 접근성을 별도로 고려해야 한다. 색상만으로 구분하지 않고, 표 데이터와 텍스트 설명을 함께 제공하며, HTML·PDF 출력의 읽기 순서를 확인해야 한다.
