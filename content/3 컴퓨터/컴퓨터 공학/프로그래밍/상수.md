# 개요

상수는 프로그램 안에서 한 번 정해지면 변하지 않는 값을 말한다. 변수와 달리 실행 중에 값이 바뀌지 않도록 약속하거나 언어 차원에서 막아 둔다.

# 쓰임

상수는 반복해서 쓰이는 값에 이름을 붙여 코드의 의미를 분명하게 한다. 예를 들어 최대 로그인 시도 횟수, 기본 글자 크기, API 주소, 수학 상수처럼 의미 있는 값에 이름을 붙인다.

# 장점

상수를 쓰면 코드 안에 숫자나 문자열이 흩어지는 것을 줄일 수 있다. 값이 바뀌어야 할 때 한 곳만 수정하면 되고, 읽는 사람도 그 값이 무엇을 뜻하는지 이해하기 쉽다.
