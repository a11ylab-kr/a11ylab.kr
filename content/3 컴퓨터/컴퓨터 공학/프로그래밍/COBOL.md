# 개요

COBOL은 Common Business-Oriented Language의 줄임말로, 금융, 행정, 보험, 회계 같은 업무용 데이터 처리에 오래 쓰인 프로그래밍 언어이다.

# 특징

영어 문장에 가까운 문법을 지향했고, 대량의 거래 처리와 레거시 시스템에서 오랫동안 사용되었다. 오래된 시스템 유지보수 문제를 이야기할 때 자주 등장한다.

# 접근성 관점

COBOL 자체보다 중요한 것은 레거시 시스템이 공공 서비스와 금융 서비스의 접근성에 미치는 영향이다. 오래된 시스템이라도 사용자-facing 서비스가 접근 가능해야 하며, 개편 과정에서 접근성 요구사항을 함께 반영해야 한다.
