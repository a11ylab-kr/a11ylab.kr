# 개요

데이터베이스는 여러 사람이 함께 쓰거나 오래 보관해야 하는 [[자료]]를 체계적으로 저장하고 관리하는 시스템이다. 단순 파일 묶음보다 검색, 수정, 권한 관리, 백업, 동시 접근을 안정적으로 다루는 데 초점이 있다.

# 종류

대표적으로 관계형 데이터베이스와 NoSQL 데이터베이스가 있다. 관계형 데이터베이스는 표와 관계를 중심으로 데이터를 저장하고 SQL로 질의한다. NoSQL 데이터베이스는 문서, 키-값, 그래프, 컬럼 등 다양한 구조를 사용한다.

# 쓰임

회원 정보, 게시글, 결제 내역, 설문 응답, 로그, 연구 데이터, 접근성 검사 결과처럼 반복적으로 조회·수정되는 정보가 데이터베이스에 저장된다.

# 접근성 관점

데이터베이스 자체는 사용자가 직접 보지 않는 경우가 많지만, 어떤 데이터를 저장하고 어떻게 구조화하느냐가 서비스 접근성에 영향을 준다. 예를 들어 이미지 대체 텍스트, 자막, 언어 정보, 접근성 오류 이력, 사용자 설정을 데이터 구조에 포함해야 접근 가능한 서비스를 만들 수 있다.
