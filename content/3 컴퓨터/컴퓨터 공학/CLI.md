# 개요

CLI는 Command Line Interface의 줄임말로, 사용자가 글자로 명령을 입력하고 결과를 텍스트로 받는 사용자 인터페이스이다. [[터미널]]이나 콘솔에서 자주 사용한다.

# 특징

CLI는 그래픽 버튼보다 처음 배우기 어렵지만, 반복 작업과 자동화에 강하다. 명령 기록을 남기고, 여러 명령을 조합하고, 서버나 개발 환경을 빠르게 제어할 수 있다.

# 접근성 관점

CLI는 텍스트 기반이라 화면 읽기 프로그램과 잘 맞을 수 있지만, 모든 CLI가 접근 가능한 것은 아니다. 색상만으로 상태를 표시하거나, 진행률 애니메이션을 반복하거나, 오류 메시지가 모호하면 접근성이 떨어진다.

접근 가능한 CLI는 명령 도움말이 명확하고, 출력 구조가 예측 가능하며, 색상 없이도 의미가 전달되고, 실패했을 때 다음 조치를 알려 주어야 한다.
