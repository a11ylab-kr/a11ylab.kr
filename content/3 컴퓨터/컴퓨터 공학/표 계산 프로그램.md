# 개요

표 계산 프로그램은 행과 열로 이루어진 셀에 값을 입력하고, 수식과 함수를 이용해 계산·분석·시각화를 수행하는 소프트웨어이다. 흔히 스프레드시트라고 부른다.

가계부, 예산, 성적표, 재고 관리, 설문 분석, 일정표, 간단한 데이터베이스처럼 숫자와 표를 다루는 일상 업무에 널리 쓰인다.

# 주요 기능

표 계산 프로그램의 핵심은 셀과 수식이다.

- 셀: 행과 열이 만나는 입력 칸
- 수식: 다른 셀 값을 참조해 계산하는 식
- 함수: 합계, 평균, 조건, 날짜, 문자열 처리 등 자주 쓰는 계산 명령
- 차트: 표 데이터를 그래프로 표현하는 기능
- 필터와 정렬: 데이터를 조건에 따라 찾고 배열하는 기능
- 피벗 테이블: 큰 표를 요약해 관점별로 집계하는 기능

대표적인 제품으로 Microsoft Excel, Google Sheets, LibreOffice Calc, Apple Numbers 등이 있다.

# 접근성 관점

표 계산 프로그램은 구조가 복잡해질수록 접근성 문제가 커진다. 셀 병합, 색상만으로 구분한 의미, 빈 행·빈 열로 만든 시각적 간격, 제목 없는 표는 [[화면 읽기 프로그램]] 사용자에게 큰 부담이 된다.

접근 가능한 스프레드시트를 만들려면 첫 행과 첫 열의 의미를 분명히 하고, 시트 이름을 알기 쉽게 붙이며, 색상 외의 텍스트 단서를 제공해야 한다. 계산 결과만 전달할 때도 원본 표보다 요약표나 설명 문서를 함께 제공하는 편이 좋다.
