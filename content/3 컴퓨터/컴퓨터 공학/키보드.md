# 개요

키보드는 [[컴퓨터]]와 디지털 기기에 문자, 숫자, 명령을 입력하는 대표적인 [[입력 장치]]이다. 여러 개의 키를 눌러 글자를 입력하거나, 단축키로 기능을 실행하거나, 메뉴와 화면 사이를 이동한다.

키보드는 데스크톱 컴퓨터뿐 아니라 노트북, 태블릿, 스마트폰용 외장 키보드, 점자 키보드, 보조공학용 대체 키보드 등 다양한 형태로 쓰인다.

# 구성

일반적인 키보드는 다음과 같은 영역을 가진다.

- 문자키: 글자와 숫자를 입력한다.
- 기능키: F1~F12처럼 프로그램 기능을 실행한다.
- 수정키: Shift, Control, Option/Alt, Command/Windows 키처럼 다른 키와 조합한다.
- 이동키: 방향키, Home, End, Page Up, Page Down 등으로 위치를 옮긴다.
- 숫자 키패드: 숫자 입력과 계산 작업에 쓰인다.

키보드 구조는 언어, 운영체제, 국가별 배열에 따라 달라진다. 한국어 환경에서는 한/영 전환, 한자 변환, 두벌식·세벌식 같은 입력 방식도 함께 고려된다.

# 접근성 관점

키보드는 접근성에서 매우 중요한 장치이다. 마우스를 쓰기 어려운 사용자, 화면을 볼 수 없어 포인터 위치를 확인하기 어려운 사용자, 스위치나 보조기기를 사용하는 사용자에게 키보드 조작 가능성은 기본 접근권과 연결된다.

웹과 앱은 키보드만으로도 모든 기능에 접근할 수 있어야 한다. 초점 순서가 논리적이어야 하고, 현재 초점 위치가 보이며, 키보드 함정 없이 빠져나올 수 있어야 한다. [[화면 읽기 프로그램]] 사용자도 대부분 키보드 명령으로 화면을 탐색한다.
