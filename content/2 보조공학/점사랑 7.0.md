# 개요

점사랑 7.0은 국립국어원 점자 종합 정보 누리집에서 제공하는 윈도용 점역 프로그램이다. 점자 문서 편집, 점자 파일 관리, 점자 파일 인쇄, 점역 환경 설정, 점역, 역점역 기능을 제공한다.[^1]

여기서 점역은 묵자 문서를 [[점자]]로 옮기는 작업을 뜻하고, 역점역은 점자 문서를 다시 묵자 문서로 옮기는 작업을 뜻한다. 점사랑 7.0은 [[한글 점자]]와 여러 점자 규정을 실제 문서 제작 환경에서 다루기 위한 도구로 볼 수 있다.

# 주요 기능

국립국어원 점자 종합 정보 누리집은 점사랑 7.0의 주요 개선 사항을 다음과 같이 안내한다.[^1]

- 범용 문서(DOCX, HWPX 등) 점역 기능 강화
- 화면 낭독기 접근성 강화
- 외국어 점역 기능 강화
- 중국어 만다린어, 광둥어 신규 지원 및 일본어 기능 보완
- 점사랑 촉각 프로그램과의 연동 기능 개발
- 점자 문서 편집, 파일 관리, 인쇄, 점역 환경 설정, 점역, 역점역 기능 제공

# 접근성 관점에서의 의미

점사랑 7.0은 점자를 아는 사용자만을 위한 도구가 아니다. 점역사, 교사, 기관 담당자, 출판·교육 자료 제작자처럼 점자 문서를 만들어야 하는 사람에게도 중요하다. 점자가 실제 생활에서 쓰이려면 점자 규정뿐 아니라 문서를 만들고, 검토하고, 인쇄하고, 배포할 수 있는 제작 환경이 필요하기 때문이다.

특히 HWPX나 DOCX 같은 범용 문서의 점역 기능은 공공문서와 교육 자료 접근성과 직접 연결된다. 다만 프로그램이 문서를 점역할 수 있다는 사실만으로 최종 점자 문서의 품질이 보장되는 것은 아니다. 원본 문서의 구조, 표와 수식, 이미지 대체 설명, 점역 규정 적용, 점역 후 교정 과정이 함께 갖추어져야 실제로 읽을 수 있는 점자 문서가 된다.

# 화면 읽기 프로그램 접근성

점사랑 7.0 안내에는 화면 낭독기 접근성 강화가 포함되어 있다. 이는 점역 프로그램 자체를 시각장애인 사용자가 [[화면 읽기 프로그램]]으로 조작할 수 있어야 한다는 점에서 중요하다. 점자를 만들고 읽는 도구가 보조공학기술과 잘 맞물리지 않으면, 정작 당사자가 점자 문서를 편집하거나 검토하는 과정에서 다시 장벽을 만날 수 있다.

따라서 점사랑 7.0의 접근성은 단순히 “점자 파일을 만들 수 있는가”가 아니라, 프로그램 인터페이스가 화면 읽기 프로그램, 키보드 조작, 파일 관리 흐름과 얼마나 잘 맞는가까지 함께 보아야 한다.
