# 개요

화면 읽기 프로그램은 단순히 화면의 글자를 음성으로 읽는 도구가 아니다. 키보드 명령과 터치 제스처를 이용해 항목 사이를 이동하고, 컨트롤을 실행하고, 문서 구조를 탐색하며, 읽기 위치와 실제 키보드 초점을 관리하는 인터페이스다.

이 문서는 Sense Reader, VoiceWith, NVDA, Windows 내레이터, JAWS, macOS·iPhone의 VoiceOver, Android의 TalkBack에서 **처음 익혀야 할 기본 명령**을 과업 중심으로 정리한다. 모든 명령을 망라한 설명서가 아니라 길을 잃었을 때 다시 시작하고 핵심 과업을 수행하기 위한 빠른 참조표다.

> [!important] 적용 범위
> 2026년 8월 3일에 확인한 공식 문서와 로컬 도움말을 기준으로 작성했다. 운영체제·제품 버전, 데스크톱·노트북 배열, 제품 등급, 브라우저, 기기 제조사, 키맵과 사용자 설정에 따라 실제 동작이 달라질 수 있다. 교육이나 접근성 평가에 사용하기 전에는 대상 환경에서 입력 도움말과 실제 조작으로 다시 확인해야 한다.

# 표기 방법

- `NVDA`: NVDA 보조 키다. 기본값은 `Insert` 또는 숫자패드 `0`이며 `Caps Lock`으로도 설정할 수 있다.
- `내레이터`: 내레이터 보조 키다. 기본값은 `Caps Lock` 또는 `Insert`다.
- `JAWS`: 이 문서의 데스크톱 배열에서는 주로 `Insert`를 보조 키로 사용한다.
- `VO`: VoiceOver 보조 키다. 기본값은 `Control+Option` 또는 `Caps Lock`이다.
- `TalkBack 키`: 외장 키보드 키맵에 따라 달라진다. TalkBack 16.2 이상의 향상된 키맵에서는 Windows 키보드의 `Windows`, Mac 키보드의 `Command`가 작업 키다.
- `Num`: Num Lock을 끈 숫자패드 키다.
- `Shift`를 함께 누르면 이전 요소로 이동하는 명령이 많지만, 제품마다 예외가 있다.

# Windows 화면 읽기 프로그램

## Sense Reader

Sense Reader는 읽기 포인터와 뷰포인터, 웹 가상커서를 사용한다. 웹에서는 현재 기본값으로 설명되는 **브라우저 탭 키 환경**과 구형 **가상커서 탭 키 환경**을 구분해야 한다.

### 시작과 기본 제어

| 과업 | 기본 명령 |
|---|---|
| 시작 | `Ctrl+Alt+S` |
| 종료 | `Insert+F4` |
| 기능 검색 | `Insert+F2` |
| 포커스 읽기 | `Ctrl+Shift+F` |
| 창 제목 읽기 | `Ctrl+Shift+T` |
| 창 내용 읽기 | `Ctrl+Shift+W` |
| 상태 표시줄 읽기 | `Ctrl+Shift+S` |
| 마지막 출력 다시 읽기 | `F12` |
| 연속 읽기 | `F11` |
| 읽기 중지 | 연속 읽기 중 `Esc` |
| 다음 키를 응용프로그램으로 전달 | 일반 환경 `Ctrl+Shift+N`, 가상커서 `Ctrl+N` |

### 읽기 포인터

| 읽기 단위 | 이전 | 현재 | 다음 |
|---|---|---|---|
| 줄 | `Num8` | `Num5` | `Num2` |
| 단어 | `Ctrl+Num4` | `Ctrl+Num5` | `Ctrl+Num6` |
| 글자 | `Num4` | `Alt+Num5` | `Num6` |

- 읽기 포인터를 현재 포커스로 이동: `Num+`
- 읽기 포인터를 캐럿 위치로 이동: `Ctrl+Num+`
- 마우스 포인터를 뷰포인터 위치로 이동: `Ctrl+Shift+Num+`
- 뷰포인터를 마우스 포인터 위치로 이동: `Alt+Shift+Num+`

### 웹 가상커서

| 과업 | 다음 | 이전 |
|---|---|---|
| 헤딩 | `H` | `Shift+H` |
| 헤딩 수준 | `1`~`6` | `Shift+1`~`Shift+6` |
| 링크 | `L` | `Shift+L` |
| 랜드마크 | `J` | `Shift+J` |
| 편집창 | `F2` | `Shift+F2` |
| 폼 컨트롤 | `N` | `Shift+N` |
| 표 | `T` | `Shift+T` |
| 목록 | `S` | `Shift+S` |
| 목록 항목 | `I` | `Shift+I` |
| 이미지 | `.` | `Shift+.` |

- 가상커서 설정·키 설정: `Ctrl+Shift+F9`
- 가상커서 사용 선택: `Ctrl+Shift+F11`
- 가상커서 사용 해제: `Ctrl+Shift+F12`
- 임시 해제: Grave 키(`` ` ``)
- 임시 해제 후 복귀: `Esc`, `Tab`, `Shift+Tab`
- 브라우저 탭 키 환경과 구형 가상커서 탭 키 환경 전환: `F9`
- 문자열 찾기: `Ctrl+F`, 다음 `F3`, 이전 `Shift+F3`

> [!warning] `F9`와 숫자키
> `F9`는 다음 브라우저 탭으로 이동하는 키가 아니라 Sense Reader의 두 가상커서 키 환경을 전환하는 키다. 브라우저 탭 이동은 `Ctrl+Tab`과 `Ctrl+Shift+Tab`을 사용한다. 브라우저 탭 키 환경에서 `1`~`6`은 헤딩 수준이고 `7`, `8`, `9`, `0`, `-`는 등록 검색어를 찾는다.

## NVDA

이 절은 NVDA 2026.1.1과 데스크톱 키보드 배열을 기준으로 한다.

### 시작과 기본 제어

| 과업 | 기본 명령 |
|---|---|
| 시작 | 설치 과정에서 바탕 화면 바로 가기를 만든 경우 `Ctrl+Alt+N` |
| 종료 | `NVDA+Q`, 이어서 `Enter` |
| 입력 도움말 | `NVDA+1` |
| NVDA 메뉴 | `NVDA+N` |
| 현재 포커스 읽기 | `NVDA+Tab` |
| 창 제목 읽기 | `NVDA+T` |
| 현재 창 읽기 | `NVDA+B` |
| 연속 읽기 | 시스템 캐럿 `NVDA+↓`, 검토 커서 `Num+` |
| 읽기 중지 | `Ctrl` |
| 다음 키를 응용프로그램으로 전달 | `NVDA+F2` |

### 검토 커서

| 읽기 단위 | 이전 | 현재 | 다음 |
|---|---|---|---|
| 줄 | `Num7` | `Num8` | `Num9` |
| 단어 | `Num4` | `Num5` | `Num6` |
| 글자 | `Num1` | `Num2` | `Num3` |

- 검토 커서를 현재 포커스로 이동: `NVDA+Num-`
- 시스템 포커스를 현재 탐색 객체로 이동: `NVDA+Shift+Num-`
- 마우스를 현재 탐색 객체로 이동: `NVDA+Num/`
- 탐색 객체를 마우스 위치로 이동: `NVDA+Num*`

### 브라우즈 모드

| 과업 | 다음 | 이전 |
|---|---|---|
| 헤딩 | `H` | `Shift+H` |
| 헤딩 수준 | `1`~`6` | `Shift+1`~`Shift+6` |
| 링크 | `K` | `Shift+K` |
| 랜드마크 | `D` | `Shift+D` |
| 편집창 | `E` | `Shift+E` |
| 폼 필드 | `F` | `Shift+F` |
| 버튼 | `B` | `Shift+B` |
| 표 | `T` | `Shift+T` |
| 목록 | `L` | `Shift+L` |
| 목록 항목 | `I` | `Shift+I` |
| 체크 상자 | `X` | `Shift+X` |

- 브라우즈 모드와 포커스 모드 전환: `NVDA+Space`
- 요소 목록: `NVDA+F7`
- 브라우즈 모드 문자열 찾기: `NVDA+Ctrl+F`
- 다음 결과: `NVDA+F3`
- 이전 결과: `NVDA+Shift+F3`

## VoiceWith

VoiceWith는 NVDA를 기반으로 한 한국어 중심 화면 읽기 프로그램이다. 2026.1.1 배포본은 NVDA 계열의 기본 조작 체계를 사용하지만 HWP 지원을 위한 고유 모듈과 수정 사항이 있다.

처음에는 다음 NVDA 계열 명령을 우선 익힐 수 있다.

- 입력 도움말: `NVDA+1`
- 현재 포커스 읽기: `NVDA+Tab`
- 창 제목 읽기: `NVDA+T`
- 연속 읽기: `NVDA+↓`
- 읽기 중지: `Ctrl`
- 브라우즈 모드와 포커스 모드 전환: `NVDA+Space`
- 웹 요소 목록: `NVDA+F7`
- 헤딩 `H`, 링크 `K`, 랜드마크 `D`, 편집창 `E`, 폼 필드 `F`, 버튼 `B`, 표 `T`

> [!note] NVDA와 같은 계열이지만 같은 제품은 아니다
> VoiceWith의 모든 기능키가 같은 버전 번호의 NVDA와 완전히 동일하다고 단정해서는 안 된다. VoiceWith 고유 HWP 기능과 수정 모듈, 사용자 설정이 있을 수 있다. `NVDA+1` 입력 도움말과 VoiceWith 공식 교재·강좌를 함께 사용해 현재 설치본에서 확인하는 것이 안전하다.

## Windows 내레이터

이 절은 Windows 11의 표준 키보드 배열을 기준으로 한다. `내레이터` 보조 키는 기본적으로 `Caps Lock` 또는 `Insert`다.

### 시작과 기본 제어

| 과업 | 기본 명령 |
|---|---|
| 시작·중지 | `Windows+Ctrl+Enter` |
| 종료 | `내레이터+Esc` |
| 입력 학습 | `내레이터+1` |
| 명령 목록 | `내레이터+F1` |
| 다음·이전 항목 | `내레이터+→` / `내레이터+←` |
| 기본 동작 실행 | `내레이터+Enter` |
| 현재 항목 읽기 | `내레이터+Tab` |
| 창 제목 읽기 | `내레이터+T` |
| 현재 창 읽기 | `내레이터+W` |
| 문서 연속 읽기 | `Ctrl+내레이터+R` 또는 `내레이터+↓` |
| 읽기 중지 | `Ctrl` |
| 다음 키를 응용프로그램으로 전달 | `내레이터+3` |
| 마지막 음성 다시 듣기 | `내레이터+X` |

### 스캔 모드

- 스캔 모드 켜기·끄기: `내레이터+Space`
- 기본 동작 실행: `Enter`
- 보조 동작 실행: `Shift+Enter`
- 헤딩 `H`, 링크 `K`, 랜드마크 `D`, 편집창 `E`, 폼 필드 `F`, 버튼 `B`, 표 `T`, 목록 `L`, 목록 항목 `I`, 체크 상자 `X`
- `Shift`를 함께 누르면 이전 요소로 이동한다.
- 특정 헤딩 수준은 `1`~`9`와 `Shift+1`~`Shift+9`를 사용한다.

## JAWS

이 절은 Freedom Scientific의 국제판 JAWS 공식 단축키와 데스크톱 배열을 기준으로 한다. 국내 Korean JAWS의 한글화와 HWP 지원 범위는 별도로 확인해야 한다.

### 시작과 기본 제어

| 과업 | 기본 명령 |
|---|---|
| 종료 | `Insert+F4` |
| 키보드 도움말 | `Insert+1` |
| 명령 검색 | `Insert+Space`, 이어서 `J` |
| 현재 포커스와 안내 읽기 | `Insert+Tab` |
| 창 제목 읽기 | `Insert+T` |
| 연속 읽기 | `Insert+↓` |
| 읽기 중지 | `Ctrl` |
| 다음 키를 응용프로그램으로 전달 | 숫자열 `Insert+3` |
| JAWS 창 열기 | `Insert+J` |
| 화면 새로 읽기 | `Insert+Esc` |

### 웹 가상 커서

- 헤딩: `H`, 이전 `Shift+H`
- 헤딩 수준: `1`~`6`, 이전 `Shift+1`~`Shift+6`
- 버튼: `B`, 편집창: `E`, 폼 컨트롤: `F`
- 표: `T`, 목록: `L`, 목록 항목: `I`
- 방문하지 않은 링크: `U`, 방문한 링크: `V`
- 링크 목록: `Insert+F7`
- 헤딩 목록: `Insert+F6`
- 폼 모드 진입: `Enter`
- 폼 모드 종료: `Num+`
- 찾기: `Ctrl+Insert+F`, 다음 `Insert+F3`, 이전 `Insert+Shift+F3`

# macOS VoiceOver

macOS VoiceOver에는 Windows의 브라우즈 모드·가상커서와 1:1로 대응하는 독립 모드가 없다. VoiceOver 커서로 이동하고, 영역이나 그룹과 상호작용하며, 필요할 때 Quick Nav와 로터를 사용한다.

| 과업 | 기본 명령 |
|---|---|
| VoiceOver 켜기·끄기 | `Command+F5` |
| 키보드 도움말 | `VO+K` |
| 도움말 메뉴 | `VO+H` |
| 다음·이전 항목 | `VO+→` / `VO+←` |
| 항목 실행 | `VO+Space` |
| 그룹과 상호작용 시작 | `VO+Shift+↓` |
| 그룹과 상호작용 종료 | `VO+Shift+↑` |
| 앱의 최상위 계층으로 이동 | `VO+Shift+Esc` |
| 로터 메뉴 열기 | `VO+U` |
| 다음 키를 앱으로 전달 | `VO+Tab` |
| 메뉴·로터 닫기 또는 동작 중단 | `Esc` 또는 `Fn+Tab` |
| 단일 문자 Quick Nav 켜기·끄기 | `VO+Q` |
| 화살표 Quick Nav 켜기·끄기 | `VO+Shift+Q` |
| 화면 커튼 켜기·끄기 | `VO+Shift+Fn+F11` |

단일 문자 Quick Nav를 켜면 `B`로 다음 버튼, `Shift+B`로 이전 버튼, 숫자키로 해당 수준의 헤딩을 탐색할 수 있다. 할당은 사용자가 변경할 수 있으므로 전체 요소 탐색은 `VO+U` 로터에서 헤딩·링크·표 등의 목록을 확인하는 방법도 함께 익히는 것이 좋다.

# iPhone·iPad VoiceOver

## 먼저 익힐 제스처

| 과업 | 제스처 |
|---|---|
| 손가락 아래 항목 듣기 | 한 손가락으로 화면을 천천히 움직이기 |
| 다음·이전 항목 | 한 손가락으로 오른쪽 / 왼쪽 쓸기 |
| 선택한 항목 실행 | 한 손가락으로 두 번 탭 |
| 화면 맨 위부터 연속 읽기 | 두 손가락으로 위로 쓸기 |
| 현재 항목부터 연속 읽기 | 두 손가락으로 아래로 쓸기 |
| 읽기 일시 정지·계속 | 두 손가락으로 한 번 탭 |
| 이전 화면 또는 알림 닫기 | 두 손가락으로 Z 모양 문지르기 |
| 아래쪽 내용 보기 | 세 손가락으로 위로 쓸기 |
| 위쪽 내용 보기 | 세 손가락으로 아래로 쓸기 |
| VoiceOver 음성 켜기·끄기 | 세 손가락으로 두 번 탭 |
| 화면 커튼 켜기·끄기 | 세 손가락으로 세 번 탭 |

## 로터

- 로터 항목 선택: 두 손가락을 화면에 대고 다이얼처럼 돌린다.
- 선택한 로터의 이전 항목 또는 값 올리기: 한 손가락으로 위로 쓸기
- 선택한 로터의 다음 항목 또는 값 내리기: 한 손가락으로 아래로 쓸기

# Android TalkBack

TalkBack 동작은 기기 제조사, Android·TalkBack 버전, 여러 손가락 동작 지원 여부와 사용자 맞춤설정에 따라 달라질 수 있다.

## 먼저 익힐 제스처

| 과업 | 제스처 |
|---|---|
| 손가락 아래 항목 듣기 | 한 손가락으로 화면을 천천히 움직이기 |
| 다음·이전 항목 | 한 손가락으로 오른쪽 / 왼쪽 쓸기 |
| 선택한 항목 실행 | 한 손가락으로 두 번 탭 |
| 위아래로 스크롤 | 두 손가락으로 위 / 아래 쓸기 |
| 홈 | 위로 쓸고 왼쪽으로 쓸기 |
| 뒤로 | 아래로 쓸고 왼쪽으로 쓸기 |
| TalkBack 메뉴 | 세 손가락으로 한 번 탭 또는 아래로 쓸고 오른쪽으로 쓸기 |
| 다음 읽기 제어 | 세 손가락으로 아래로 쓸기 |
| 이전 읽기 제어 | 세 손가락으로 위로 쓸기 |
| 현재 항목 다음부터 읽기 | 두 손가락으로 세 번 탭 |
| 음성 일시 정지·계속 | 두 손가락으로 한 번 탭 |
| 다음 제스처를 시스템에 전달 | 네 손가락으로 두 번 탭한 뒤 길게 누르기 |

여러 손가락 동작을 지원하는지는 TalkBack을 켠 상태에서 세 손가락으로 한 번 탭해 확인할 수 있다. TalkBack 메뉴가 열리면 여러 손가락 동작을 지원하는 환경이다.

## 외장 키보드

TalkBack 16.2 이상을 처음 활성화하면 웹 탐색 중심의 **향상된 키맵**이 기본으로 설정된다. 이전 설치나 사용자 설정에서는 기본 키맵일 수 있다.

- 다음·이전 항목: `TalkBack 키+→` / `TalkBack 키+←`
- 항목 실행: `TalkBack 키+Enter`
- 음성 중지: TalkBack 16.2 이상 `Ctrl`
- 현재 항목부터 읽기: `TalkBack 키+Ctrl+Shift+Enter`
- 맨 위부터 읽기: `TalkBack 키+Ctrl+Enter`
- 탐색 모드 켜기·끄기: `TalkBack 키` 두 번
- 단축키 연습: `TalkBack 키+0`
- 단축키 목록: `TalkBack 키+Shift+/`
- 시스템으로 키 전달: `TalkBack 키+Shift+Esc`

Chrome 탐색 모드에서는 `TalkBack 키`와 함께 헤딩 `H`, 랜드마크 `D`, 버튼 `B`, 편집창 `E`, 링크 `L`, 표 `T` 등을 사용한다. `Shift`를 추가하면 이전 요소로 이동한다.

# 길을 잃었을 때 확인할 순서

1. 현재 키보드 포커스나 화면 읽기 프로그램 커서가 어디에 있는지 다시 읽는다.
2. 브라우즈 모드·스캔 모드·가상커서·Quick Nav·TalkBack 탐색 모드의 현재 상태를 확인한다.
3. 입력 도움말이나 단축키 연습에서 누르려는 키가 화면 읽기 프로그램 명령인지 확인한다.
4. 웹 앱이나 응용프로그램의 단축키를 사용해야 한다면 다음 키 전달 명령을 사용한다.
5. 그래도 이동하지 않으면 `Tab`·`Shift+Tab`, 문서 처음 `Ctrl+Home`, 앱 전환 등 운영체제·응용프로그램 기본 명령으로 위치를 회복한다.
6. 평가 기록에는 운영체제·브라우저·앱·화면 읽기 프로그램의 버전과 사용한 모드를 함께 적는다.
