# 개요

점자 표시 장치는 컴퓨터, 스마트폰, 태블릿 같은 기기의 텍스트 정보를 촉각 [[점자]]로 출력하는 [[보조공학기술]] 장치이다. 영어로는 `braille display` 또는 `refreshable braille display`라고 부른다.

장치 안의 작은 핀들이 올라오고 내려가며 점자 셀을 만들고, 사용자가 화면을 이동하거나 커서를 옮기면 표시되는 점자도 계속 바뀐다. 그래서 종이에 찍힌 고정 점자와 달리, 전자 문서를 손끝으로 실시간 읽고 편집할 수 있다.[^1]

# 구성과 동작

점자 표시 장치는 보통 다음 요소를 포함한다.

- 점자 셀: 핀이 올라오고 내려가며 한 글자 또는 한 칸의 점자를 표시한다.
- 커서 라우팅 키: 특정 점자 셀 위치로 커서를 이동하거나 선택한다.
- 이동·탐색 키: 줄, 문단, 화면 단위로 내용을 이동한다.
- 연결 방식: USB, 블루투스 등으로 컴퓨터나 모바일 기기와 연결한다.
- 입력 키보드: 제품에 따라 점자식 입력 키 또는 일반 키보드를 함께 제공한다.

점자 표시 장치는 대개 [[화면 읽기 프로그램]]과 함께 작동한다. 화면 읽기 프로그램이 화면의 텍스트와 초점 정보를 해석하고, 점자 표시 장치는 그 결과를 사용자가 읽을 수 있는 촉각 정보로 바꾼다.

# 점자 정보 단말기와의 차이

점자 표시 장치는 독립 제품일 수도 있고, [[점자 정보 단말기]] 안에 내장된 부품일 수도 있다. 단독 점자 표시 장치는 주로 다른 기기와 연결해 화면 내용을 점자로 읽는 데 쓰인다. 반면 점자 정보 단말기는 문서 작성, 파일 관리, 인터넷, 메일, 일정, 학습 도구 등 독립적인 컴퓨팅 기능을 함께 제공하는 경우가 많다.

다만 실제 제품 경계는 점점 흐려지고 있다. 일부 점자 표시 장치는 메모장이나 파일 저장 기능을 제공하고, 일부 점자 정보 단말기는 외부 기기에 연결되어 점자 표시 장치처럼 쓰인다.

# 접근성 관점에서의 의미

점자 표시 장치는 음성 출력만으로는 충분하지 않은 작업에서 특히 중요하다. 철자 확인, 코드 작성, 표·수식 읽기, 외국어 학습, 긴 문서 편집, 조용한 환경에서의 작업은 점자 출력이 있을 때 훨씬 안정적이다.

또한 점자 표시 장치는 점자 문해력과도 연결된다. 화면을 음성으로만 듣는 환경이 늘수록 점자를 실제로 읽고 쓰는 기회가 줄어들 수 있다. 전자점자 장치는 디지털 환경에서 점자가 계속 살아 있는 읽기 매체가 되도록 돕는다.
