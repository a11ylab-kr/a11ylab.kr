# 기반 기술 및 문제 해결 가능성
현재(2026-03-02) 본 사이트는 [[React]]로 구축된 [[정적 사이트 생성기]]긴  [[2 Area/생산성 도구/Obsidian 이야기/Quartz]]를 기반으로 동작한다. 따라서 사이트에 대한 문제는 대부분 대응이 가능하리라 예상한다. 사이트 단에서 해결한 문제는 내용을 잘 검토하여 [Quartz GitHub 저장소](https://github.com/jackyzha0/quartz)를 통해 수정을 요청하거나 코드를 공헌하는 방식으로 자체 프레임워크의 기능을 개선 가능할 것이다.
