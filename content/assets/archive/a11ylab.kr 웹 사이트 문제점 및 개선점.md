# 개요

[[알리의 접근성 연구소]] 웹사이트의 문제점과 개선 사항을 기록한다. 이 문서는 완성된 평가 보고서가 아니라, 사이트를 운영하면서 발견한 접근성·사용성 문제를 모아 두는 작업 기록이다.

# 기반 기술 및 문제 해결 가능성

현재(2026-03-02) 본 사이트는 [[React]]로 구축된 [[정적 사이트 생성기]]인 [[Quartz]]를 기반으로 동작한다. 따라서 사이트 자체에서 발생하는 문제는 대부분 코드 수정으로 대응할 수 있으리라 예상한다. 사이트 단에서 해결한 문제는 내용을 잘 검토한 뒤 [Quartz GitHub 저장소](https://github.com/jackyzha0/quartz)에 수정을 요청하거나 코드를 공헌하는 방식으로 자체 프레임워크의 기능 개선으로 이어 갈 수 있다.
